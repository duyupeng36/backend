# 01-notes · 技术笔记

按《2.5 年学习计划》的 11 个模块组织，与月度安排（M1–M28）一一对应。

## 笔记规范（强制）

1. **目录以编号开头**：所有目录一律带两位数字前缀（`01-…`），按学习顺序编号。
2. **每篇笔记只记录一个知识点**：一个概念 / 一种机制 / 一个方法 = 一篇笔记；超过一个知识点就拆成多篇。
3. **文件命名**：`NN-知识点名.md`，模块内从 `01` 开始连续编号，编号即学习顺序。
4. **清单即规划**：各模块 README 列出计划中的笔记文件名；学一个写一个，文件建好即视为该知识点完成。
5. 每篇笔记建议结构：是什么 → 为什么 / 解决什么问题 → 怎么用（示例代码）→ 项目里哪里用到 → 延伸阅读（英文优先）。
