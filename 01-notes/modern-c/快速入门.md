# 快速入门

## 第一个C程序

学习 C 语言的最好方式就是使用它编写程序。我们编写的第一个C程序就是向终端输出 `"To C, or not to C: that is the question."`。首先，需要创建一个名为 [pun.c](../../02-practice/modern-c/pun.c) 的文件，然后在文件中输入以下内容

```c
/* pun.c - 向终端输出 To C, or not to C: that is the question.*/

#include <stdio.h>

int main(void) {
  printf("To C, or not to C: that is the question.\n");
  return 0;
}
```

> [!NOTE]
>
> C 源代码文件我们使用 `.c` 作为文件扩展名：这通常是编译器的要求；也标识着这个文件是使用 C 语言编写的程序文本
