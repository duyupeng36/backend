# 01-C语言概览 · 总结

> 3 个知识点：命令式编程 → 编译型语言 → 编译器是朋友

---

## 核心脉络

C 是**命令式 + 编译型**语言。程序员写指令，编译器翻译成机器码，四阶段流程：**预处理 → 编译 → 汇编 → 链接**。

```
源码(.c) → 预处理(-E) → .i → 编译(-S) → .s → 汇编(-c) → .o → 链接 → 可执行文件
```

## 三个关键认知

1. **C 是命令式的** — 程序 = 函数 → 语句 → 表达式，顺序执行，每步改变状态
2. **C 是编译型的** — 翻译在运行前完成，可移植性靠"为不同平台写编译器"实现
3. **编译器是朋友** — 启用 `-Wall -Wextra -Werror`，零警告通过是底线

## 易错点

- `main` 必须返回 `int`，不能写 `void main()`
- 编译器选项 `-E`（只预处理）、`-S`（只编译到汇编）、`-c`（只编译到目标文件）可以分步观察编译过程
- 编译器只保证**可观察行为**（volatile、I/O）不变，其余可任意优化
