## 速览

定义是声明的特例——它不仅告诉编译器名字和类型，还分配内存（创建对象）。`int x = 42;` 是定义——创建了 `x` 这个 `int` 对象并赋值 42。声明可以多次，定义只能一次（单一定义规则）。

---

## 是什么

**定义**（definition）是声明的特例，它不仅告诉编译器标识符的名字和类型，还为对象分配内存（或为函数生成指令）。《Modern C》中定义必须伴随初始化。同一个对象或函数在整个程序中只能有一个定义（单一定义规则）。

---

## 详细解释

声明与定义的对比：

| 维度 | 声明（Declaration） | 定义（Definition） |
|--|-------------------|-------------------|
| 做什么 | 告诉编译器标识符代表什么 | 告诉编译器对象在哪里、值是什么 |
| 创建实体？ | ❌ 不创建 | ✅ 创建（分配存储空间） |
| 可以重复？ | ✅ 可以有多个一致声明 | ❌ 每个对象/函数只能有一个 |

> [!TIP]
>
> 声明是向编译承诺存在一个程序实体，定义就是**兑现承诺**；即，创建程序实体。对于数据对象就是分配存储空间；函数就是生成函数的指令；类型别名只是创建数据对象的蓝图，仅声明即可。

《Modern C》中的定义被认为是 **声明 + 初始化器**；换句话说，**定义总是应该伴随初始化**。例如

```c
size_t i = 0;	// 声明 + 初始化 = 定义
```

这行代码告诉编译器标识符 `i` 是 `size_t` 类型的数据对象，并且应该为它分配内存空间并将 $0$ 写入内存空间中

示例程序 `getting-started.c` 中，数组 `A` 初始化称为 **指定初始化**(C99起)。方括号 `[n] = value` 指明数组中索引为 `n` 的元素值为 `value`。任何没有在初始化列表中指定的位置，自动设置为 $0$

`````c
double A[5] = {
    [0] = 9.0,       // 第0个元素 = 9.0
    [1] = 2.9,       // 第1个元素 = 2.9
    [4] = 3.E+25,    // 第4个元素 = 3.E+25
    [3] = .00007,    // 第3个元素 = .00007
};
`````

> **数组索引**：数组索引(下标)从 $0$ 开始，`A[0]` 是数组 `A` 的第一个元素，`A[n-1]` 是数组的最后一个元素（共 $n$ 个元素）。索引(下标)可以理解为**元素距离数组起点的偏移量**

**函数定义**：函数定义很简单，只需要在函数声明后跟随 `{...}` 函数体就是函数定义

```c
// 只是声明（后面有分号）
int main(int, char*[]);

// 声明 + {} 函数体 = 定义
int main(int argc, [[maybe_unused]] char* argv[argc + 1]) {
    // ...
}
```

> [!WARNING]
> 数据对象或函数必须有且只有一个定义
> 
> + 没有定义 → 链接器不知道在哪里找它 → 链接错误
> + 多于一个定义 → 链接器不知道该用哪个 → 冲突错误
