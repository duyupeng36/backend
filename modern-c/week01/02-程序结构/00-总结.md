# 02-程序结构 · 总结

> 4 个知识点：语法 → 声明 → 定义 → 语句

---

## 核心脉络

C 程序由六种基本构件组成：**关键字、标识符、运算符、字面量、标点、注释**。程序的层次结构：

```
程序 → 函数 → 语句 → 表达式 → 运算符 + 操作数
```

## 三个关键认知

1. **声明 vs 定义** — 声明是承诺（"这个名字存在"），定义是兑现（分配内存）。声明可多次，定义只能一次
2. **作用域** — 从声明点开始，到块/文件末尾结束。内层隐藏外层
3. **语句是执行单位** — 五类：表达式语句、选择、迭代、跳转、复合语句

## 声明 vs 定义速查

| 维度 | 声明 | 定义 |
|------|------|------|
| 做什么 | 告诉编译器名字和类型 | 分配内存 + 可能初始化 |
| 可重复？ | ✅ 多次一致声明 | ❌ 只能一次 |
| 示例 | `extern int x;` | `int x = 42;` |

## 易错点

- 同一个标点（`*`、`[]`）可能有多种含义，靠上下文判断
- `main` 函数是托管环境的执行入口，有且只有一个
- 声明的作用域从**声明点**开始，不是块开头
