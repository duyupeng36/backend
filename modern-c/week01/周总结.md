## 本周核心收获

第 1 周建立了 C 语言的全局认知框架。从"程序是什么"到"值怎么表示"，5 个主题形成完整链条：

```
C语言是什么（命令式+编译型）
    ↓
程序长什么样（语法+声明+定义+语句）
    ↓
走哪条路（if/for/while/switch）
    ↓
路上算什么（表达式+运算符）
    ↓
算的东西是什么类型（类型系统+位运算）
```

## 必须记住的 5 件事

1. **编译四阶段**：预处理 → 编译 → 汇编 → 链接。用 `-E`/`-S`/`-c` 分步观察
2. **声明 vs 定义**：声明可多次，定义只能一次。声明是承诺，定义是兑现
3. **非零即真**：C 的条件判断没有布尔类型，0 为假，非 0 为真
4. **无符号溢出回绕，有符号溢出 UB**：这是定义行为的区别，不是 bug
5. **混合 signed/unsigned 是坑**：`-1 < 0U` 是 false，记住这个经典陷阱

## 最容易犯的错

| 错误 | 原因 | 修复 |
|------|------|------|
| `void main()` | main 必须返回 int | `int main(void)` |
| `i <= ARRAY_SIZE` | 数组索引从 0 开始 | `i < ARRAY_SIZE` |
| `switch` 忘记 `break` | 穿透到下一个 case | 每个 case 加 break |
| `-1 < 0U` 得到 false | -1 被隐式转为 UINT_MAX | 避免混合 signed/unsigned |
| `0.1 + 0.2 != 0.3` | 浮点精度有限 | 用误差范围比较 |
