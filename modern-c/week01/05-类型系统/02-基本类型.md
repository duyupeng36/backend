# 基本类型

> week01 · C 语言全貌 · 知识点 22

> 状态：☑ 已完成

## 速览

C 基本类型由关键字（整数、浮点）和头文件（语义类型）提供。整数类型有 Rank 等级（1~5），C 标准只规定最小宽度。四种数据模型（LP32/ILP32/LLP64/LP64）决定了 `int`/`long`/指针的具体宽度。不要追求精确宽度，用语义类型。

---

## 是什么

**基本类型**是 C 语言内置的、不可再分的类型，是所有其他类型的基础。C 的基本类型由两部分组成：关键字提供的类型（如 `int`、`double`）和头文件提供的语义类型（如 `uint32_t`、`size_t`）。整数类型有 Rank 等级（0~5），决定了类型转换的优先级。

---

## 详细解释

下表列出了由关键字提供的基本类型

| 类别           | 系统名称             | Rank | 类别              | 系统名称               | Rank |
| -------------- | -------------------- | ---- | ----------------- | ---------------------- | ---- |
| **无符号整数** | `bool`               | 0    | **有/无符号整数** | `char`                 | 1    |
|                | `unsigned char`      | 1    | **有符号整数**    | `signed char`          | 1    |
|                | `unsigned short`     | 2    |                   | `signed short`         | 2    |
|                | `unsigned int`       | 3    |                   | `signed int`           | 3    |
|                | `unsigned long`      | 4    |                   | `signed long`          | 4    |
|                | `unsigned long long` | 5    |                   | `signed long long`     | 5    |
| **实浮点数**   | `float`              |      | **复浮点数**      | `float _Complex`       |      |
|                | `double`             |      |                   | `double _Complex`      |      |
|                | `long double`        |      |                   | `long double _Complex` |      |

C 标准为每种 Rank 整数类型规定了最小宽度。下表列出了每个 Rank 的 C 标准规定的最小尺寸以及具体实现选择的具体尺寸。

| Rand | C 标准(位) | LP32(位) | ILP32(位) | LLP64(位) | LP64(位) |
| ---- | ---------- | -------- | --------- | --------- | -------- |
| 1    | $\ge 8$    | $8$      | $8$       | $8$       | $8$      |
| 2    | $\ge 16$   | $16$     | $16$      | $16$      | $16$     |
| 3    | $\ge 16$   | $16$     | $32$      | $32$      | $32$     |
| 4    | $\ge 32$   | $32$     | $32$      | $32$      | $64$     |
| 5    | $\ge 64$   | $64$     | $64$      | $64$      | $64$     |

具体实现对基本类型大小的选择称为数据模型，被广泛接收的由 $4$ 种

| 模型      | int  | long   | pointer | 典型平台                |
| --------- | ---- | ------ | ------- | ----------------------- |
| **LP32**  | 16   | 32     | 32      | Win16 API               |
| **ILP32** | 32   | 32     | 32      | Win32、32位 Linux/macOS |
| **LLP64** | 32   | 32     | 64      | Win64 API               |
| **LP64**  | 32   | **64** | 64      | 64位 Linux/macOS        |

> 虽然 `bool`（Rank 为 $0$）只需要 $1$ 位就可以完全表示，但是计算机访问内存的最小单元就是字节($8$位)。因此，`bool` 类型在大多数具体平台上都是 $8$ 位
>

> [!WARNING]
>
> **不追求"精确宽度"**。C 标准只规定了基本类型最小宽度，不规定精确宽度。精确宽度由具体实现定义，不同的实现可能会选择不同的宽度

**浮点类型**：C 标准并未规定浮点数类型应该采用怎样的浮点格式，只是说明了如果平台支持 IEEE-754 浮点格式就采用该格式

| 类型          | 格式               | 典型大小 |
| ------------- | ------------------ | -------- |
| `float`       | IEEE-754 binary32  | 32 bit   |
| `double`      | IEEE-754 binary64  | 64 bit   |
| `long double` | IEEE-754 binary128 | 128 bit  |

> [!TIP]
>
> 无论如何，浮点类型能够表示值的范围应该远大于整数类型

---

## 代码示例

```c
/* basic_types.c — 查看当前平台的基本类型宽度 */
#include <stdio.h>
#include <stdint.h>

int main(void) {
    printf("=== 当前平台数据模型 ===\n");
    printf("char      : %2zu 字节\n", sizeof(char));
    printf("short     : %2zu 字节\n", sizeof(short));
    printf("int       : %2zu 字节\n", sizeof(int));
    printf("long      : %2zu 字节\n", sizeof(long));
    printf("long long : %2zu 字节\n", sizeof(long long));
    printf("指针      : %2zu 字节\n", sizeof(void*));
    // 根据 int=4, long=8, 指针=8 → LP64 模型
}
```
