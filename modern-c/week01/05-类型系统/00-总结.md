## 核心脉络

C 的类型系统分两层：**关键字提供的基本类型** + **头文件提供的语义类型**。

```
基本类型（关键字）
├── 整数：char / short / int / long / long long（各有 signed/unsigned）
├── 浮点：float / double / long double
└── bool（C23）

语义类型（<stdint.h>）
├── 定宽：int8_t / uint32_t / int64_t ...
└── 最小宽度：int_least8_t / int_fast32_t ...
```

## 三个关键认知

1. **C 标准只规定最小宽度，不规定精确宽度** — 用 `<stdint.h>` 的语义类型，别猜
2. **四种数据模型**（LP32/ILP32/LLP64/LP64）决定了 int/long/指针的实际宽度
3. **整数提升** — 小于 int 的类型运算时自动提升为 int

## 类型 Rank 等级

```
bool(0) < char(1) < short(2) < int(3) < long(4) < long long(5)
```

运算时，低 Rank 向高 Rank 转换。混合 signed/unsigned 时要小心。

## 位运算 = 集合运算

| 运算符 | 集合含义 | 示例 |
|--------|----------|------|
| `|` | 并集 | `A \| B` |
| `&` | 交集 | `A & B` |
| `^` | 对称差 | `A ^ B` |
| `~` | 补集 | `~A` |
| `<<` `>>` | 移位（乘/除 2 的幂） | `A << 3` |

## 易错点

- **混合 signed/unsigned 比较**：`-1 < 0U` 是 false（-1 转成 UINT_MAX）
- **窄化转换危险**：`unsigned short g = 0x80000000;` 截断为 0
- **有符号溢出是 UB**：`signed int c = 0x8000'0000;` 未定义行为
- **位运算操作的是位模式**，不是数值大小
- `~A` 和 `-A` 相差 1，原因是补码表示
