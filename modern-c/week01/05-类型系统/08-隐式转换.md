# 隐式转换

> week01 · C 语言全貌 · 知识点 28

> 状态：☑ 已完成

## 速览

编译器自动完成的类型转换。算术转换规则：先整数提升 → 整数向浮点转 → 同符号按 Rank 升 → 混合符号依赖平台。避免混合有符号和无符号操作数。对象运算符右操作数转为左操作数类型。窄化转换（大类型→小类型）非常危险，应禁止。

---

## 是什么

计算机执行运算时，通常要求操作数具有相同的尺寸和表示方式；也就是说，操作数的类型必须相同才能执行运算。C 语言并没有这些要求，因为 C 编译器可以帮助我们统一运算符操作数的类型，这种由编译器完成的类型转换称为 **隐式类型转换**

---

## 详细解释

隐式类型转换中必须要理解的是算术转换，即运算符操作数类型不同是发生的转换。对于值运算符转换规则很简单

+ 规则一：执行整数提升，如果操作数类型统一，则类型转换完成
    + 补充：如果是一元运算符，结果类型就是整数提升后的操作数类型
+ 规则二：整数类型向浮点数类型转换，只要有一个操作数是浮点类型，另一个操作数就转换为浮点类型的值
+ 规则三：相同符号的整数类型按照 Rank 等级从低到高进行转换
+ 规则四：混合符号的整数类型转换规则比较复杂
    1. 相同 Rank 等级的有符号类型向无符号类型转换
    2. Rank 等级相差$1$ 时取决于平台
        1. `INT_WIDTH < LONG_WIDTH` 的平台上，`unsigned int` 的值被转换为 `signed long` 类型的值
        2. `INT_WIDTH == LONG_WIDTH` 的平台上，`signed long` 类型的值被转换为 `unsigned int` 类型的值

> [!WARNING]
>
> 总结：当有符号和无符号操作数混用时，隐式类型转换依赖于平台；因此，**避免混合有符号和无符号操作数**；能使用无符号就使用无符号

对于对象运算符，转换规则是固定的：右操作数转换左操作数（对象）类型的值。此外，调用函数时，转换规则也是固定的：实际参数转换为形式参数类型的值

```c
double       a = 1;              // 无害；值能放入类型
signed short b = -1;             // 无害；值能放入类型
signed int   c = 0x8000'0000;    // 危险；值太大，放不下类型
signed int   d = -0x8000'0000;   // 危险；值太大，放不下类型
signed int   e = -2'147'483'648; // 无害；值能放入类型
unsigned short g = 0x8000'0000;   // 丢失信息；值为 0
```

> [!WARNING]
>
> 对象运算符的左操作数(对象)的类型决定了整个表达式的类型；如果右操作数太大以至于无法放入左操作数，此时就会发生**窄化类型转换**。
>
> 窄化类型转换非常危险，应该禁止出现

---

## 代码示例

```c
/* implicit_convert.c — 隐式转换的陷阱和规则 */
#include <stdio.h>
#include <limits.h>

int main(void) {
    // 规则一：整数提升
    char a = 1, b = 2;
    printf("sizeof(a+b) = %zu (提升为 int)\n\n", sizeof(a + b));

    // 规则二：整数→浮点
    printf("1 + 0.0  : sizeof=%zu (double)\n", sizeof(1 + 0.0));
    printf("INT_MAX + 0.0F 可能丢失精度\n\n");

    // 规则三：相同符号向高 Rank 转 (1L→1LL)
    // 规则四：同 Rank 有符号→无符号 (1→1U)
    printf("sizeof(1U + 1)  = %zu (unsigned)\n", sizeof(1U + 1));
    printf("sizeof(1L + 1LL) = %zu (long long, 向高 Rank 转)\n\n", sizeof(1L + 1LL));

    // 教材的核心演示：混合符号性的危险
    printf("=== 混合 signed/unsigned 比较 ===\n");
    printf("-1 < 0   : %d (预期 true)\n", -1 < 0);
    printf("-1 < 0U  : %d (预期 true，实际 false! -1 被转成 UINT_MAX)\n", -1 < 0U);

    // 窄化转换陷阱
    unsigned u = 0x80000000;
    unsigned short g = u;   // 截断，只保留低 16 位
    printf("\n0x80000000 → unsigned short: %u (变成了 0)\n", g);

    // 一元 - 的类型
    printf("\n=== 一元 - 的类型 ===\n");
    printf("sizeof(-1)  = %zu (signed int)\n", sizeof(-1));
    printf("sizeof(-1U) = %zu (unsigned, 值是 UINT_MAX)\n", sizeof(-1U));
}
```
