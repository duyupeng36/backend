## 速览

浮点数用 IEEE 754 格式表示，由符号位、指数位、尾数位三部分组成。`float` 是 32 位（1+8+23），`double` 是 64 位（1+11+52）。特殊值包括 ±0、±∞、NaN。浮点数不能精确表示所有十进制小数（如 0.1），这是浮点运算误差的根源。

---

## 是什么

**浮点数的二进制表示**是 IEEE 754 标准定义的格式，用符号位（1位）、指数位（偏移编码）、尾数位（规格化小数）三部分来表示实数。C 语言的 `float` 和 `double` 类型遵循此标准。

---

## 详细解释

### IEEE 754 格式

**float (32位)**

| 字段 | 符号 | 指数 | 尾数 |
|------|------|------|------|
| **位宽** | 1 bit | 8 bits | 23 bits |
| **位置** | bit31 | bit30-23 | bit22-0 |

**double (64位)**

| 字段 | 符号 | 指数 | 尾数 |
|------|------|------|------|
| **位宽** | 1 bit | 11 bits | 52 bits |
| **位置** | bit63 | bit62-52 | bit51-0 |

### 值的计算

对于规格化数（指数不全为0也不全为1）：
$$
\text{value} = (-1)^{\text{sign}} \times 2^{\text{exponent} - \text{bias}} \times (1 + \text{mantissa})
$$


其中：
- `sign`：符号位，0 正 1 负
- `exponent`：指数位的无符号整数值
- `bias`：偏移量，`float` 为 $2^{7} - 1 = 127$，`double` 为 $1023 = 2^{10} - 1$。IEEE 754 规定的偏移量是 $2^{n-1} - 1$
- `mantissa`：尾数位表示的小数部分（隐含前导 1）

### 示例：将 12.25 转换为 float

1. 整数部分：$12 = (1100)_{2}$
2. 小数部分：$0.25 = (0.01)_{2}$
3. 合并：$12.25 = (1100.01)_{2} = 1.10001 × 2^{3}$
4. 符号位：0（正数）
5. 指数：$3 + 127(\text{bias})= 130 = 10000010_{2}$
6. 尾数：10001000000000000000000（去掉前导 1）

最终：`0 10000010 10001000000000000000000`

### 特殊值

| 指数 | 尾数 | 含义 |
|------|------|------|
| 全0 | 全0 | $\pm 0$（取决于符号位） |
| 全0 | 非0 | 非规格化数（极小值） |
| 全1 | 全0 | $\pm \infty$ |
| 全1 | 非0 | $NaN$（非数字） |

### 精度限制

| 类型 | 位数 | 精度（十进制） |
|------|------|----------------|
| float | 32 | ~7 位有效数字 |
| double | 64 | ~15 位有效数字 |

```c
// 经典的浮点误差示例
double x = 0.1 + 0.2;
if (x == 0.3) {
    printf("相等\n");      // 不会执行
} else {
    printf("不相等：%a\n", x);  // 输出 0.30000000000000004
}
```

## 代码示例

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    float f = 12.25f;
    unsigned char *bytes = (unsigned char*)&f;
    
    printf("12.25 的二进制表示：\n");
    for (int i = 3; i >= 0; --i) {
        printf("%08x ", bytes[i]);
    }
    printf("\n");
    
    // 验证 IEEE 754 格式
    printf("符号位: %d\n", (*(unsigned*)&f >> 31) & 1);
    printf("指数位: %d\n", ((*(unsigned*)&f >> 23) & 0xFF) - 127);
    
    return 0;
}
```
