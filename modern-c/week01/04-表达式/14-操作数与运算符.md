## 速览

表达式是由操作数和运算符组成的计算值的代码。C 的运算符分三类：值运算符（算出新值）、对象运算符（修改对象本身）、类型运算符（返回大小/对齐）。`size_t` 表示 `[0, SIZE_MAX]` 范围内的无符号值，永远非负。

---

## 是什么

表达式（expression）是一段**计算值**的代码；它根据其他值算出另一个值。表达式由**操作数**和**运算符**组成（运算符可以没有）

> [!TIP]
>
> 最简单的表达式就是一个常量或标识符；它们的用途只是单纯的为了获取值

---

## 详细解释

我们将围绕 `size_t` 类型展开学习 C 中的表达式。`size_t` 的值域范围是 `[0, SIZE_MAX]`，`SIZE_MAX` 的大小取决于具体平台

| 平台        | `SIZE_MAX` 的值               |
| ----------- | ----------------------------- |
| $16$ 位平台 | $2^{16}-1=65535$              |
| $32$ 位平台 | $2^{32}-1$ 大约是 $43$ 亿     |
| $64$ 位平台 | $2^{64}-1$ 大约是 $1844$ 亿亿 |

> [!TIP]
>
> 不需要记忆，也不需要自行计算 `SIZE_MAX` 的值。C 标准头文件 `<stdint.h>` 中提供了 `SIZE_MAX` 宏
>
> `size_t` 类型属于 C 的无符号整数类型；意味着 **`size_t` 类型的值永远不会小于 $0$**；这意味着 `size_t` 类型能够表示 `[0, SIZE_MAX]` 范围内的值

**操作数与运算符**：C 把计算拆分成两个角色：操作数（operand）是被操作的东西，运算符（operator）是执行操作的符号。例如 `a + b` 中，`a` 和 `b` 是操作数，`+` 是运算符。C 的运算符按操作实体可以分为 $3$ 类

| 类型       | 操作对象                 | 举例                              |
| ---------- | ------------------------ | --------------------------------- |
| 值运算符   | 操作值，算出新值         | `+` `-` `*` `/` `%` `==` `!` `&&` |
| 对象运算符 | 操作对象本身，可能改变它 | `=` `+=` `++` `--` `&`            |
| 类型运算符 | 操作类型，返回大小/对齐  | `sizeof ` `alignof`               |

以下三张表来自《Modern C》第 4 章，列出了 C 的全部运算符。不需要一次性记住；学习过程中自然会熟悉。

### 表 4.1 值运算符

作用于**值**，算出新值。`@` 表示运算符位置，`a` 和 `b` 是操作数。

| 运算符 | 别名 | 形式 | 说明 | 类别 |
|--------|------|------|------|------|
| `+` `-` | | `a@b` | 指针 ± 整数 → 指针 | 指针算术 |
| `+` `-` `*` `/` | | `a@b` | 算术型 ±×÷ 算术型 → 算术型 | 算术 |
| `+` `-` | | `@a` | 一元正负号 | 算术 |
| `%` | | `a@b` | 整数取余（`a%b` = `a - (a/b)*b`） | 算术 |
| `~` | `compl` | `@a` | 按位取反 | 位 |
| `&` | `bitand` | `a@b` | 按位与 | 位 |
| `\|` | `bitor` | `a@b` | 按位或 | 位 |
| `^` | `xor` | `a@b` | 按位异或 | 位 |
| `<<` `>>` | | `a@b` | 左移 / 右移 | 位 |
| `==` `<` `>` `<=` `>=` | | `a@b` | 相等/关系比较 → 0 或 1 | 比较 |
| `!=` | `not_eq` | `a@b` | 不等比较 → 0 或 1 | 比较 |
| `!` | `not` | `@a` | 逻辑非（0→1, 非0→0） | 逻辑 |
| `&&` `\|\|` | `and` `or` | `a@b` | 逻辑与 / 逻辑或（短路求值） | 逻辑 |
| `.` | | `a@m` | 结构体成员访问 | 成员 |
| `*` | | `@a` | 解引用指针 → 对象 | 引用 |
| `[]` | | `a[b]` | 下标访问（`a[b]` ≡ `*(a+b)`） | 成员 |
| `->` | | `a@m` | 指针->成员（`a->m` ≡ `(*a).m`） | 成员 |
| `()` | | `a(b...)` | 函数调用 | 调用 |
| `sizeof` | | `@a` 或 `@(T)` | 返回操作数的字节大小 → `size_t` | 大小 |
| `alignof` | `_Alignof` | `@(T)` | 返回类型对齐要求 → `size_t` | 对齐 |

### 表 4.2 对象运算符

作用于**对象**（内存位置），可能修改它。`o` 是对象，`a` 是附加值。

| 运算符 | 形式 | 说明 | 类别 |
|--------|------|------|------|
| | `o` | 数组/函数退化为指针 | 退化 |
| `=` | `o = a` | 赋值 | 赋值 |
| `+=` `-=` `*=` `/=` | `o @= a` | 复合赋值（算术） | 算术 |
| `%=` | `o %= a` | 复合赋值（取余） | 算术 |
| `++` `--` | `@o` `o@` | 前缀/后缀自增自减 | 算术 |
| `&=` `\|=` `^=` | `o @= a` | 复合赋值（位运算） | 位 |
| `<<=` `>>=` | `o @= a` | 复合赋值（移位） | 位 |
| `.` | `o.m` | 结构体成员访问 | 成员 |
| `[]` | `o[a]` | 下标访问 | 成员 |
| `&` | `&o` | 取地址 → 指针 | 地址 |

### 表 4.3 类型运算符

返回 `size_t` 类型的整数常量（ICE）。

| 运算符 | 形式 | 说明 |
|--------|------|------|
| `sizeof` | `sizeof(T)` | 类型 T 的字节大小 |
| `alignof` | `alignof(T)` | 类型 T 的对齐要求 |
| `offsetof` | `offsetof(T, m)` | 结构体成员 m 的字节偏移 |
