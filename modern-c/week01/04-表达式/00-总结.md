# 04-表达式与运算符 · 总结

> 8 个知识点：表达式 → 算术运算 → 无符号溢出 → 修改对象的运算符 → 比较运算 → 逻辑运算 → 三元运算 → 抽象状态机

---

## 核心脉络

表达式 = 操作数 + 运算符，计算出一个值。C 的运算符分三类：

| 类型 | 操作对象 | 效果 |
|------|----------|------|
| **值运算符** | 值 | 算出新值（`+` `-` `*` `/` `%` `==` `!` `&&`） |
| **对象运算符** | 对象（内存） | 修改对象（`=` `+=` `++` `--`） |
| **类型运算符** | 类型 | 返回大小（`sizeof` `alignof`） |

## 三个关键认知

1. **比较运算返回 0/1（数字），不是 true/false** — `3 > 2` 的值是 `1`，类型是 `int`
2. **逻辑运算符短路求值** — `&&` 左边为假不算右边，`||` 左边为真不算右边
3. **无符号溢出是定义行为（回绕），有符号溢出是未定义行为**

## 溢出规则

```c
unsigned int x = UINT_MAX;  // 最大值
x += 1;                     // 回绕到 0，定义行为

int y = INT_MAX;
y += 1;                     // 未定义行为！编译器可以做任何事
```

## 抽象状态机思维

程序 = 抽象状态机。值是数学实体，类型决定范围和运算，二进制表示桥接两者。写可移植代码的原则：**关注值，不关注表示**。

## 易错点

- `sizeof` 是运算符，不是函数（对类型加括号，对变量可不加）
- `&&` 和 `||` 有短路行为，右边可能不执行
- 无符号回绕在某些场景下是故意设计（如哈希计算）
- 运算符优先级记不住就加括号
