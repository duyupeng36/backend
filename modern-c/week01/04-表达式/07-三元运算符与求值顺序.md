# 三元运算符与求值顺序

> week01 · C 语言全貌 · 知识点 20

> 状态：☑ 已完成

## 速览

三元运算符 `condition ? a : b` 是 `if-else` 的表达式形式，也具有短路特性（只执行被选中的分支）。`&&`、`||`、`?:` 是 C 中少数保证求值顺序的运算符。其他运算符的子表达式求值顺序不确定，函数调用不应有副作用。

---

## 是什么

**三元运算符** `? :` 需要三个操作数，是 `if-else` 语句的表达式形式。**求值顺序**指子表达式的计算顺序，C 标准并未规定大多数运算符的求值顺序。

---

## 详细解释

三元运算符 `? :` 需要三个操作，分别位于这两个符号的两边：`condition ? true-expression : false-expression`

+ 当 `condition` 的值为 `true(1)` 时，表达式的值就是 `true-expression` 表达式的值
+ 当 `condition` 的值为 `false(0)` 时，表达式的值就是 `false-expression` 表达式的值

```c
size_t size_min(size_t a, size_t b) {
    return (a < b) ? a : b;   // 如果 a<b，返回 a；否则返回 b
}
```

> [!TIP]
> 与 `&&` 和 `||` 一样，运算符 `?:` 也具有短路特性: *只执行被选中的那个分支*
>
> ```c
> b != 0 ? (a / b) : 0; // b = 0 时，a / b 不会执行 
> ```

运算符 `&&` `||` 和 `?:` 都是 C 中少数几个**保证求值顺序**的运算符。其他大多数运算符（比如 `f(a) + g(b)`）的执行顺序是不确定的。

另一个保证求值顺序的运算符是逗号运算符（`,`），已经在 `for` 语句中见过它。这里补充说明一点：逗号运算符连接的所有子表达式按顺序从左到右进行计算，最后一个子表达式的值就是逗号运算符返回的值

> [!WARNING]
>
> 在表达式 `f(a) + g(b)` 中，`f` 和 `g` 谁先执行取决于编译器。如果 `f` 或 `g` 有副作用（修改外部变量），结果不可预测。因此，表达式必须遵守的铁律：**表达式中的函数调用不应该有副作用**

---

## 代码示例

```c
/* ternary.c — 三元运算符演示 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int a = 10, b = 20;

    // 基本用法：替代简单的 if-else
    int max = (a > b) ? a : b;
    printf("max(%d, %d) = %d\n", a, b, max);  // 20

    // 嵌套使用：三个数求最大
    int c = 15;
    int max3 = (a > b) ? ((a > c) ? a : c)
                       : ((b > c) ? b : c);
    printf("max(%d, %d, %d) = %d\n", a, b, c, max3);  // 20

    // 短路：未选中的分支不执行
    int x = 0;
    int safe = (x != 0) ? (100 / x) : -1;
    printf("safe = %d\n", safe);  // -1, 不会除零

    return EXIT_SUCCESS;
}
```
