# 算术运算

> week01 · C 语言全貌 · 知识点 15

> 状态：☑ 已完成

## 速览

C 提供 `+` `-` `*` `/` `%` 五个算术运算符。整数除法丢弃余数，`%` 提供余数。无符号运算恒成立 `a == (a/b)*b + (a%b)`。除以 0 是未定义行为，程序可能崩溃。`/` 和 `%` 的结果一定小于操作数。

---

## 是什么

**算术运算符**是用于执行数学计算的值运算符，它们读取操作数并计算出新的值，操作数本身不会被修改。C 提供了 5 个算术运算符：

| 运算符  | 描述                                 |
| ------- | ------------------------------------ |
| `a + b` | 执行加法运算，获得 `a` 加上 `b` 的和 |
| `a - b` | 执行减法运算，获得 `a` 减去 `b` 的差 |
| `a * b` | 执行乘法运算，获得 `a` 乘以 `b` 的积 |
| `a / b` | 执行除法运算，获得 `a` 除以 `b` 的商 |
| `a % b` | 执行模运算，获得 `a` 除以 `b` 的余数 |

---

## 详细解释

这些运算符的运算符工作方式与数学上大致相同。这些运算符都需要两个操作数，被称为 **二元运算符**。对于 `+` 和 `-`，它们还有 **一元** 形式的变体：`-b` 对 `b` 的值取负数，`+a` 就是 `a` 本身。此外，值得额外探讨的算术运算符就是 **除法和取模**

> [!TIP]
>
> **整数除法**：当运算符 `/` 的两个操作数都是整数时，执行整数除法：表达式 `a / b` 计算的是 `b` 能够放进 `a` 多少次，余数部分直接丢弃。运算符 `%` 是对整数除法的补充：提供了获取整数除法中余数的方法。因此，表达式 `a == (a / b) * b + (a % b)` 一定是成立。用数学公式表示为
> $$
> a = \left\lfloor \frac{a}{b} \right\rfloor \times b + a \bmod b
> $$
> 整数除法有一个绝对禁区：**右操作数(`b`)不能是 $0$**。除以 $0$ 在 C 中是未定义行为，程序可能直接崩溃

```c
size_t a = 45;
size_t b = 7;
size_t c = (a - b) * 2;   // (45-7)*2 = 76
size_t d = a - b * 2;      // 45-14 = 31  乘除优先级高于加减
```

这里 `c` 的值一定是 $76$，`d` 的值是 $31$。圆括号用于分组子表达式，以强制运算符优先绑定的操作数。

## 代码示例

`celsius.c` — 华氏温度转换为摄氏温度，转换公式：$C=\frac{5}{9}\times\left(F - 32\right)$

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char* argv[argc + 1]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <fahrenheit>\n", argv[0]);
        return EXIT_FAILURE;
    }
    double fahrenheit = strtod(argv[1], nullptr);

    double celsius = 5.0 / 9.0 * (fahrenheit - 32.0);
    printf("%.4g °F= %.4g °C\n", fahrenheit, celsius);
    return EXIT_SUCCESS;
}
```

`upc.c` — 计算通用产品代码的校验位

```c
/* upc.c - 计算通用产品代码的校验位 */

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(int argc, char* argv[argc + 1]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <UPC CODE>\n", argv[0]);
        return EXIT_FAILURE;
    }

    char const * const upc = argv[1];

    if (strlen(upc) != 12) {
        fprintf(stderr, "Please enter the correct UPC code.\n");
        return EXIT_FAILURE;
    }

    long odd = 0;
    long even = 0;

    // 奇数位相加
    for (size_t i = 0, stop = strlen(upc) - 1; i <= stop; i += 2) {
        odd += upc[i] - '0';
    }
    // 偶数位相加
    for (size_t i = 1, stop = strlen(upc) - 1; i < stop; i += 2) {
        even += upc[i] - '0';
    }

    long check = 9 - ((3 * odd) + even - 1) % 10;

    if (check == upc[strlen(upc) - 1] - '0') {
        printf("check digit is %ld. Check SUCCESS\n", check);
    } else {
        printf("Check digit must be %d. But got %ld\n", upc[strlen(upc) - 1] - '0', check);
    }

    return EXIT_SUCCESS;

}
```

> UPC 代码共 $13$ 位，其中最后一位是校验位。校验位的计算方法如下
>
> 1. 奇数位数字相加之和再乘以 $3$
> 2. 偶数位数字相加
> 3. 步骤1的结果加上步骤2的结果再减去 $1$
> 4. 用 $9$ 减去步骤3的结果除以 $10$ 取余数
