# 算术运算

> week01 · C 语言全貌 · 知识点 15

> 状态：☑ 已完成

## 速览

C 提供 `+` `-` `*` `/` `%` 五个算术运算符。整数除法丢弃余数，`%` 提供余数。无符号运算恒成立 `a == (a/b)*b + (a%b)`。除以 0 是未定义行为，程序可能崩溃。`/` 和 `%` 的结果一定小于操作数。

---

## 是什么

**算术运算符**是用于执行数学计算的值运算符，它们读取操作数并计算出新的值，操作数本身不会被修改。C 提供了 5 个算术运算符：

| 运算符  | 描述                                 |
| ------- | ------------------------------------ |
| `a + b` | 执行加法运算，获得 `a` 加上 `b` 的和 |
| `a - b` | 执行减法运算，获得 `a` 减去 `b` 的差 |
| `a * b` | 执行乘法运算，获得 `a` 乘以 `b` 的积 |
| `a / b` | 执行除法运算，获得 `a` 除以 `b` 的商 |
| `a % b` | 执行模运算，获得 `a` 除以 `b` 的余数 |

---

## 详细解释

这些运算符的运算符工作方式与数学上大致相同。这些运算符都需要两个操作数，被称为 **二元运算符**。对于 `+` 和 `-`，它们还有 **一元** 形式的变体：`-b` 对 `b` 的值取负数，`+a` 就是 `a` 本身。此外，值得额外探讨的算术运算符就是 **除法和取模**

> [!TIP]
>
> **整数除法**：当运算符 `/` 的两个操作数都是整数时，执行整数除法：表达式 `a / b` 计算的是 `b` 能够放进 `a` 多少次，余数部分直接丢弃。运算符 `%` 是对整数除法的补充：提供了获取整数除法中余数的方法。因此，表达式 `a == (a / b) * b + (a % b)` 一定是成立。用数学公式表示为
> $$
> a = \left\lfloor \frac{a}{b} \right\rfloor \times b + a \bmod b
> $$
> 整数除法有一个绝对禁区：**右操作数(`b`)不能是 $0$**。除以 $0$ 在 C 中是未定义行为，程序可能直接崩溃

```c
size_t a = 45;
size_t b = 7;
size_t c = (a - b) * 2;   // (45-7)*2 = 76
size_t d = a - b * 2;      // 45-14 = 31  乘除优先级高于加减
```

这里 `c` 的值一定是 $76$，`d` 的值是 $31$。圆括号用于分组子表达式，以强制运算符优先绑定的操作数。

## 代码示例

`primes.c` — 统计 $N$ 以内素数的个数（暴力解法：从第一个素数 $2$ 开始遍历直到 $N$）

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char* argv[argc + 1]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <number>\n", argv[0]);
        return EXIT_FAILURE;
    }

    size_t number = strtoull(argv[1], nullptr, 0);

    size_t count = 0;

    // 从 1 开始遍历到 number
    for (size_t target = 2; target <= number; ++target) {
        bool flag = true;
        // 对于每个 number
        for (size_t factor = 2;  factor * factor <= target; ++factor) {
            if (!(target % factor)) {
                flag = false;
                break;
            }
        }
        if (flag) {
            ++count;
        }
    }

    printf("There are a total of %zu prime numbers in %zu\n", count, number);
    return EXIT_SUCCESS;
}
```

`primes2.c` —  统计 $N$ 以内素数的个数（优化一：除了 $2$ 以外，所有素数都是奇数；奇数的因子不可能是偶数）


`primes3.c` — 统计 $N$ 以内素数的个数（优化2：利用孪生素数猜想生成可选素数序列）

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char* argv[argc + 1]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <number>\n", argv[0]);
        return EXIT_FAILURE;
    }

    size_t number = strtoull(argv[1], nullptr, 0);

    size_t count = 3;  // 2 3 5 是已知的素数

    // 从 1 开始遍历到 number
    for (size_t target = 7, step = 4; target <= number; target = target + step, step = 6 - step) {
        // 对于大于 5 的数，5 的倍数一定不是素数
        if (!(target % 5)) {
            continue;
        }
        bool flag = true;
        // 对于每个 number
        for (size_t factor = 3;  factor * factor <= target; factor = factor + 2) {
            if (!(target % factor)) {
                flag = false;
                break;
            }
        }
        if (flag) {
            ++count;
        }
    }

    printf("There are a total of %zu prime numbers in %zu\n", count, number);
    return EXIT_SUCCESS;
}
```

> [!TIP]
>
> 孪生素数猜想：除了 $2$ 之外，存在无穷多个素数 $p$，使得 $p+2$ 也是素数。根据这个猜想，从 $5$ 开始，相邻两个素数满足 $(6k-1, 6k+1)$
