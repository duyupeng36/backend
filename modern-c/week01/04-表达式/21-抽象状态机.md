# 抽象状态机

## 速览

程序描述抽象状态机，状态由值、类型和二进制表示决定。值是抽象数学实体，类型决定范围和运算，二进制表示桥接类型和值。对象表示是内存中的位模式，与平台相关。编译器只保证可观察行为（volatile、文件 I/O）不变，其他可任意优化。

---

## 是什么

程序文本描述了一个**抽象状态机**，它规定了程序如何从一种状态转移到下一种状态。这些状态由值、类型和二进制表示决定。

---

## 详细解释

从三个核心概念开始

| 概念                                | 解释                                                         |
| ----------------------------------- | ------------------------------------------------------------ |
| 值（value）                         | 抽象的数学实体（只是一种概念）                               |
| 类型（type）                        | 附加在值上的属性（值的范围、能做那些运算）                   |
| 二进制表示（binary representation） | 桥接类型和值的数学公式（如何用位模式描述值，依赖平台特征值） |
| 对象表示（object representation）    | 内存中实际存储的位模式（平台相关）                           |

> [!TIP]
>
> 值和值的表示是两回事：例如数值 $12$，可以表示成阿拉伯数字 $12$、罗马数字 $XII$、英文 twelve。表示方式不同，但值本身不变
>
> 计算机也是一样的。同一个值，不同的类型下，二进制表示可能完全不同。学习 C 语言和核心原则：**C 程序关注的值而不是其表示**

+ 值是一种抽象数学实体，独立于任何计算机存在；C 程序的语义都是围绕值展开的。

+ 类型附加在值上属性，它决定了：（1）值的范围，（2）能做那些运算。例如，对于值 $255$，如果存储在类型是 `unsigned char` 对象中就是合法的；如果存储在 `signed char` 对象中，就会溢出。

+ 二进制表示也是一种抽象概念：在数学上，规定了如何用位模式表示特定类型的值。例如，无符号整数
    $$
    \text{value} = \sum_{i=0}^{n-1} \text{bit}_i \times 2^i
    $$
    在任何平台上，这个公式都是通用的；只是这个 $n$ 在不同的平台上可能不同，它称为平台的特征值。

+ 对象表示是内存中实际是如何存储位模式。涉及字节序、对齐填充等概念。与平台相关

> 想要写出可移植的代码，就不要去想那些平台细节：例如，这个整数在内存里是几个字节、什么字节序（对象表示）。甚至是不需要去关注二进制表示

C 标准规定了每种类型应该使用怎样的二进制表示以及与平台相关的特征值；只要知道了操作数的值以及平台相关的特征值，操作的结果就是可推断的。例如，对于 `size_t` 类型的操作，需要检查操作数和 `SIZE_WIDTH`（表示 `size_t` 类型位模式长度）特征值，就可以完全确定

**优化**：编译器只需要保证程序的**可观察行为**不变，编译器可以任意调整我们的代码。C 标准规定了几个不能进行优化的事实：(1) `volatile` 访问，（2）文件 I/O，（3）交互式 I/O。其他全是可优化的空间。

## 代码示例

编译器优化示例

```c
size_t a = 45;
size_t b = 7;
size_t c = (a - b) * 2;
printf("c is %zu\n", c);
```

编译器发现 `a` `b` `c` 后面不再使用，可以在编译时计算出 `c = 76`，根本不给 `a` 和 `b` 分配内容；甚至更狠一点，直接输出 `"c is 76\n"`
