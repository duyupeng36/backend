# 无符号溢出与回绕

> week01 · C 语言全貌 · 知识点 16

> 状态：☑ 已完成

## 速览

无符号整数算术总是定义良好的。溢出时发生回绕，本质是对 `SIZE_MAX + 1` 取模。`/` 和 `%` 结果一定小于操作数，不可能溢出。回绕是可预测的数学行为，不是"错误"。

---

## 是什么

无符号整数的算术运算总是定义良好的。当运算结果超出类型能够存储的最大值时，C 语言会 **回绕**：本质上就是对真实结果进行了一次模 `SIZE_MAX + 1` 操作

---

## 详细解释

对于无符号类型 `size_t`，算术运算符总是定义良好的，计算发生溢出也可以确定溢出后的值：无符号整数的算术运算符本质上就是在 `SIZE_MAX + 1` 中进行 **回绕**：对于无符号整数 `a` 和 `b`，任何算术运算的结果都是对 `SIZE_MAX + 1` 取模后的结果；即 `a op b = (a op b) % (SIZE_MAX + 1)`。用数学方式表示为
$$
a\ \text{op}\ b = (a\ \text{op}\ b) \bmod {\text{SIZE\_MAX} + 1}
$$
由于无符号算术的回绕机制，任何算术运算符在无符号整数上都有良好的定义

> [!TIP]
>
> 运算符 `/` 和 `%` 操作的结果一定会小于操作数。因此，它们的计算结果一定不可能出现溢出情形

---

## 代码示例

```c
/* 演示无符号溢出回绕 */
#include <stdint.h>
#include <stdio.h>

int main(void) {
    size_t a = SIZE_MAX;
    printf("SIZE_MAX + 1 = %zu\n", a + 1);   // 输出 0

    size_t b = 0;
    printf("0 - 1 = %zu\n", b - 1);           // 输出 SIZE_MAX

    // 溢出等价于取模
    printf("(SIZE_MAX + 1) %% (SIZE_MAX + 1) = %zu\n",
           (SIZE_MAX + 1) % (SIZE_MAX + 1));  // 编译器可能警告，但结果正确
}
```
