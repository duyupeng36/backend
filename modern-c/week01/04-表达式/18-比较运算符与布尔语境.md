# 比较运算符与布尔语境

> week01 · C 语言全貌 · 知识点 18

> 状态：☑ 已完成

## 速览

C 有六个比较运算符，返回 `0` 或 `1`（数字，不是抽象的 `true/false`）。"数值即真值"，比较结果可参与算术运算和做数组索引。三个互斥关系 `(a < b) + (a == b) + (a > b)` 恒为 1。

---

## 是什么

比较运算符是用于比较两个值，其操作结果是逻辑值 `true` 或 `false`。然而，C 语言的核心准则是 **数值即真值**：比较运算符返回的值始终是 `0` 或 `1`

---

## 详细解释

C 提供了六个比较运算符；但是，C 的核心准则 **数值即真值**，这六个比较运算符的操作结果仍然是数字。也就是说，比较运算符返回的不是 "真" 或 "假" 这两个抽象的概念，而返回的是数字 $1$ 或 $0$；

```c
a == b;  // a 和 b 的值相等，这个表达式的值是 1；否则，该表达式的值是 0
a < b;   // a 小于 b 时，这个表达式的值时 1；其他情况都是 0
```

既然如此；比较结果可以出现在任何整数可以出现的地方。例如，参与算术运算和作为数组的索引

```c
size_t c = (a < b) + (a == b) + (a > b); // c 的值一定是 1（a 和 b 一定会曼满足其中一个条件）

double largeA[N] = { ... };
size_t sign[2] = { 0, 0 };
for (size_t i = 0; i < N; ++i) {
    sign[(largeA[i] < 1.0)] += 1;   // true(1) 或 false(0) 直接当索引
}
// sign[0] = 大于等于 1.0 的数量
// sign[1] = 严格小于 1.0 的数量
```

> 表达式 `sign[(largeA[i] < 1.0)] += 1;` 只使用了一行就做到了 `if` 语句先判断后累加才能作为的结果
