# 比较运算符与布尔语境

> week01 · C 语言全貌 · 知识点 18

> 状态：☑ 已完成

## 速览

C 有六个比较运算符，返回 `0` 或 `1`（数字，不是抽象的 `true/false`）。"数值即真值"，比较结果可参与算术运算和做数组索引。三个互斥关系 `(a < b) + (a == b) + (a > b)` 恒为 1。

---

## 是什么

比较运算符是用于比较两个值，其操作结果是逻辑值 `true` 或 `false`。然而，C 语言的核心准则是 **数值即真值**：比较运算符返回的值始终是 `0` 或 `1`

---

## 详细解释

C 提供了六个比较运算符；但是，C 的核心准则 **数值即真值**，这六个比较运算符的操作结果仍然是数字。也就是说，比较运算符返回的不是 "真" 或 "假" 这两个抽象的概念，而返回的是数字 $1$ 或 $0$；

```c
a == b;  // a 和 b 的值相等，这个表达式的值是 1；否则，该表达式的值是 0
a < b;   // a 小于 b 时，这个表达式的值时 1；其他情况都是 0
```

既然如此；比较结果可以出现在任何整数可以出现的地方。例如，参与算术运算和作为数组的索引

```c
size_t c = (a < b) + (a == b) + (a > b); // c 的值一定是 1（a 和 b 一定会曼满足其中一个条件）

double largeA[N] = { ... };
size_t sign[2] = { 0, 0 };
for (size_t i = 0; i < N; ++i) {
    sign[(largeA[i] < 1.0)] += 1;   // true(1) 或 false(0) 直接当索引
}
// sign[0] = 大于等于 1.0 的数量
// sign[1] = 严格小于 1.0 的数量
```

> 表达式 `sign[(largeA[i] < 1.0)] += 1;` 只使用了一行就做到了 `if` 语句先判断后累加才能作为的结果

## 代码示例

`binsearch.c` — 从一个有序数组中查找一个元素（二分查找）

```c
/* binsearch.c — 从一个有序数组中查找一个元素 */

#include <stdio.h>
#include <stdlib.h>
#include <strings.h>
int main(void) {

    size_t size = 0;

    printf("请输入数组大小: ");
    scanf("%zu", &size);

    long numbers[size];

    printf("请数组 %zu 个有序的整数: ", size);
    for (size_t i = 0; i < size; ++i) {
        scanf("%ld", &numbers[i]);
    }

    long target = 0;
    printf("输入需要查找的目标值: ");
    scanf("%ld", &target);

    long left = 0;
    long right = size - 1;
    long index = -1;
    while (left <= right) {
        // 整数除法
        long mid = (left + right) / 2;
        if (target < numbers[mid]) {
            right = mid - 1;
        } else if (target > numbers[mid]) {
            left = mid + 1;
        } else {
            index = mid;
            break;
        }
    }

    if (index == -1) {
        printf("没找到目标值 %ld\n", target);
    } else {
        printf("找到目标值 %ld 的索引为 %ld\n", target, index);
    }

    return  EXIT_SUCCESS;
}
```
