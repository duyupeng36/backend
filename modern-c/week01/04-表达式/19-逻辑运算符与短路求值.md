# 逻辑运算符与短路求值

> week01 · C 语言全貌 · 知识点 19

> 状态：☑ 已完成

## 速览

`!` 取反，`&&` 两边都真才真，`||` 一边真就真。`&&` 和 `||` 有短路特性：左操作数已能确定结果时，右操作数不执行（如避免除零）。`!!` 双重否定可将任意值标准化为 `0` 或 `1`。

---

## 是什么

逻辑运算符是用来连接多个条件并判断它们真假的符号。因此，逻辑运算符作用于那些已经被假定表示 `false` 或 `true` （即：`0` 或 `1`）的值

---

## 详细解释

C 语言提供了 $3$ 个逻辑运算符：`!`(非)、`&&`(与)、`||`(或)。它们操作真值（0 或非 0），同时返回的也是真值（0 或 1）。下表列出了

| `a`     | `!a`    | `a && b`<br />(`b` 为 `true`) | `a && b`<br />(`b` 为 `false`) | `a || b` <br />(`b` 为 `true`) | `a && b`<br />(`b` 为 `false`) |
| ------- | ------- | ----------------------------- | ------------------------------ | ------------------------------ | ------------------------------ |
| `false` | `true`  | `false`                       | `false`                        | `true`                         | `false`                        |
| `true`  | `false` | `true`                        | `false`                        | `true`                         | `true`                         |

>  [!TIP]
>
> 这表总结起来就: `&&` 两边都真才真，`||` 一边真就真，`!` 对逻辑值取反

**`&&` 和 `||` 短路特性**：运算符 `&&` 和 `||` 的左操作数已经能确定结果，右操作数根本不会进行计算。下面的代码片段演示了这个特性

```c
if (b != 0 && (a / b) > 1) {  // b=0 时，(a/b) 永远不会执行
	++x;
}

// 等价于
if (b) {
    if (a / b > 1) ++x;
}
```

`b != 0` 为假时，由 `&&` 构成的表达式一定是假，C 直接跳过右边的 `a / b`。因此，永远不会出现除零的情况。同理，由 `!!` 构成的表达式的左操作数为真时，C 也会跳过右操作数的计算。

> [!TIP]
>
> 双重否定 `!!`: `!!x` 进行两次取反，其作用就是把任意值标准化为 $0$ 或 $1$
>
> ```c
> double largeA[N] = { ... };
> size_t isset[2] = { 0, 0 };
> for (size_t i = 0; i < N; ++i) {
>     isset[!!largeA[i]] += 1;   // !!x: 非零→1, 零→0
> }
> // isset[0] = 0.0 的个数
> // isset[1] = 非零的个数（不仅仅是 1.0）
> ```

---

## 代码示例

```c
/* logic.c — 逻辑运算符和短路求值 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // 短路求值：第二个操作数可能不执行
    int a = 0;
    printf("a && ++a: %d, a=%d\n", a && ++a, a);   // 0, a=0 (++a 没执行)

    a = 1;
    printf("a || ++a: %d, a=%d\n", a || ++a, a);    // 1, a=1 (++a 没执行)

    // 双重否定：标准化为 0 或 1
    printf("!!0   = %d\n", !!0);     // 0
    printf("!!42  = %d\n", !!42);    // 1
    printf("!!-1  = %d\n", !!-1);    // 1

    return EXIT_SUCCESS;
}
```
