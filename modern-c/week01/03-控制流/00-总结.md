# 03-控制流 · 总结

> 6 个知识点：条件执行 → for → while → do-while → break/continue → 多路选择

---

## 核心脉络

C 的控制流分三类：**选择**（if/switch）、**迭代**（for/while/do-while）、**跳转**（break/continue/return/goto）。所有条件判断基于**非零即真**。

## 控制流速查表

| 结构 | 适用场景 | 特点 |
|------|----------|------|
| `if/else if/else` | 二选一/多选一 | 最基础的分支 |
| `for` | 已知循环次数 | 初始化、条件、迭代三合一 |
| `while` | 未知循环次数，先判断 | 可能一次都不执行 |
| `do-while` | 未知循环次数，先执行 | 至少执行一次 |
| `switch/case` | 多路整数匹配 | 必须 break，否则穿透 |
| `break` | 跳出当前循环/switch | 只跳一层 |
| `continue` | 跳过本次迭代 | for/while 回到条件判断，do-while 回到条件判断 |

## 三个关键认知

1. **非零即真** — C 没有布尔类型（C23 有 `_Bool`），0 为假，非 0 为真
2. **switch 穿透** — 忘记 break 是经典 bug，但有时故意利用穿透
3. **do-while 至少一次** — 适合"先做再说"的场景（如输入验证、菜单）

## 易错点

- `switch` 的 case 必须是**整数常量表达式**
- `break` 只跳出**最内层**循环/switch
- `for` 循环中声明的变量作用域仅限于循环体
- 悬空 else 问题：`if` 没有 `{}` 时，`else` 匹配最近的未匹配 `if`

## 与下一组的衔接

控制流决定了"走哪条路"，表达式与运算符决定了"路上算什么"。
