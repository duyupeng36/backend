# 修改对象的运算符

> week01 · C 语言全貌 · 知识点 17

> 状态：☑ 已完成

## 速览

赋值 `=` 和复合赋值 `op=` 直接修改对象。`++`/`--` 有前缀和后缀形式：前缀先加后用，后缀先用后加。建议始终用前缀 `++i`。铁律：同一个表达式中最多修改一个对象，不要写 `a = b = c += ++d` 这种代码。

---

## 是什么

算术运算符是值运算符，它们只是读取操作数并计算出新的值，操作数本身不会被修改。而修改对象的运算符不一样：它们直接修改对象本身

---

## 详细解释

**赋值与复合赋值**：运算符 `=` 用于赋值（前面我们已经见过了）；它的左操作数必须是一个**可寻址的对象**（能写入的内存）；右操作数是值。在 C 语言中，赋值也是一个表达式，其值就是将修改后对象的值。下面的表达式在 C 中是合法的

```c
a = b = 42; // 在 C 中是合法的
```

这表达式首先将 `42` 赋值给 `b`，然后将 `b = 42` 的值赋值给 `a`。它等价于 `a = (b = 43)` 

赋值表达式还可以与算术运算符组合使用，即 `op=`（中间不允许有空格）；表达式 `a op= b` 等价于 `a = a op (b)` 

```c
a += 7;  	// 等价于 a = a + 7
a *= 2;  	// 等价于 a = a * 2
a /= c + 2; // 等价于 a = a / (c + 2)
```

> [!WARNING]
>
> 注意，复合赋值运算符右侧一点要先计算出值，然后才能执行运算符。换句话说，`a = a op (b)` 中的圆括号 `(b)` 是不可以被省略的

变量自增(`+1`) 和递减(`-1`) 在 C 语言非常常用，C 为此定义了两个运算符 `++` 和 `--`；它们可以用作前缀运算符和后缀运算

+ 表达式 `++i` 的值是加 $1$ 后的值(`i + 1`)
+ 表达式 `i--` 的值是减 $1$ 前的值(`i`)

> 无论如何 `++` 和 `--` 始终会修改对象的值(对操作数的影响是相同的)。但是，我们始终建议用作前缀；因为 `++i` 不会产生临时对象，直接就修改变量 `i` 的值；而 `i++` 会产生一个临时对象（现代编译器可能优化掉这个操作）

还有一点需要注意：有其他运算符与 `++` 混合使用时，应该非常小心

```c
size_t a = 5;
size_t b = ++a;   // a 先变 6，b = 6
size_t c = a++;   // c 先拿旧值 6，然后 a 变 7
```

> [!WARNING]
>
> 必须遵守一个原则：**同一个表达式中，最多修改一个对象**；表达式中修改对象（副作用）会让代码出现难以预测
>
> 不要再一个表达式中出现多个修改对象的代码；例如，`a = b = c += ++d`。虽然 C 标准没有禁止这种操作，但是一定不要这样写
>
> + **可读性为零**——没人一眼能看出最终值
> + **求值顺序不确定**——不同编译器可能给出不同结果

## 代码示例

`primes3.c` — 统计 $N$ 以内素数的个数

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char* argv[argc + 1]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <number>\n", argv[0]);
        return EXIT_FAILURE;
    }

    size_t number = strtoull(argv[1], nullptr, 0);

    size_t count = 3;  // 2 3 5 是已知的素数

    // 从 1 开始遍历到 number
    for (size_t target = 7, step = 4; target <= number; target += step, step = 6 - step) {
        // 对于大于 5 的数，5 的倍数一定不是素数
        if (!(target % 5)) {
            continue;
        }
        bool flag = true;
        // 对于每个 number
        for (size_t factor = 3;  factor * factor <= target; factor += 2) {
            if (!(target % factor)) {
                flag = false;
                break;
            }
        }
        if (flag) {
            ++count;
        }
    }

    printf("There are a total of %zu prime numbers in %zu\n", count, number);
    return EXIT_SUCCESS;
}
```

> + `target = target + step` 修改为 `target += step` 
>
> + `factor = factor + 2` 修改为了 `factor += 2`
