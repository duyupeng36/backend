## 是什么

`stdio.h` 是 C 标准库中用于输入输出的头文件。它提供从最基本的单字符输出（`putchar`）到格式化输出（`printf`）再到文件操作（`fopen/fclose`）的完整 I/O 功能。所有 I/O 操作都围绕**流**（stream）的概念展开

---

## 详细解释

### 流和文件指针

**流**是 C 标准库对 I/O 设备的抽象层，隐藏了底层物理设备的差异。程序通过读写流来操作数据，不直接接触磁盘、终端、管道等具体设备。

+ **流是有方向的**：输入流（读）和输出流（写）
+ **流有缓冲**：数据先写入内存缓冲区，再批量传输到设备
+ **流有状态**：位置指针、错误标志、文件结束标志

`FILE` 是 C 标准库定义的不透明结构体类型，内部包含流的所有状态信息。`FILE*` 就是指向这个结构体的指针。当我们拿到 `FILE*`，就等于拿到了一个流。下图演示了使用 `FILE*` 操作流的完整过程

```mermaid
graph LR
    A["🖥️ 程序代码<br/>fopen / fread / fwrite / fclose"] -->|"返回"| B["📄 FILE* 流句柄<br/>(FILE 结构体指针)"]
    B -->|"封装"| C["📦 流 (Stream)<br/>缓冲区 + 位置指针 + 状态标志"]
    C -->|"关联"| D["🔢 底层文件描述符<br/>fd (整数)"]
    D -->|"系统调用"| E["⚙️ 操作系统内核<br/>read() / write()"]
    E -->|"驱动"| F["💾 物理设备<br/>磁盘 / 终端 / 网络"]
```

| 层             | 代码示例                          | 关键点                                            |
| -------------- | --------------------------------- | ------------------------------------------------- |
| 程序代码       | `FILE *fp = fopen("a.txt", "r");` | 用户接口，所有 I/O 操作的起点                     |
| FILE* 流句柄   | `FILE` 结构体指针                 | C 标准库定义，内部包含 fd、缓冲区指针、状态标志   |
| 流 (缓冲+状态) | `buf`, `pos`, `eof`, `error`      | 全缓冲(文件)/行缓冲(终端)/无缓冲(stderr)          |
| 底层 fd        | `fileno(fp)` → `int fd`           | 进程打开文件表的索引，0=stdin, 1=stdout, 2=stderr |
| OS 内核        | `read(fd, buf, n)`                | 内核维护 fd→inode 映射，管理缓冲页缓存            |
| 物理设备       | `/dev/sda`, `/dev/tty`            | 磁盘扇区、终端 TTY、网卡等硬件                    |

> [!TIP]
>
> C 程序启动时自动打开三个流
>
> | 名称     | FILE*     | 对应                                   |
> | -------- | --------- | -------------------------------------- |
> | 标准输入 | `stdin`   | 键盘（默认）                           |
> | 标准输出 | `stdout ` | 屏幕（默认，文本行缓冲，二进制块缓冲） |
> | 标准错误 | ` stderr` | 屏幕（默认，无缓冲）                   |
>
> 它们可以通过 `<stdio.h>` 头文件中定义的宏访问

我们之前使用过的 `printf` `puts` 就是向标准输出 `stdout` 写入数据，随后操作系统会将 `stdout` 中的数据显示在屏幕上；`sacnf` 就是从 `stdin` 中读取数据并按照规定的格式转换为对应类型的值

> [!WARNING]
>
> `FILE` 是一个**不透明类型**：我们不需要知道 `FILE` 内部结构（具体细节），只需通过函数接口使用它

标准IO流可以操作任何设备，这里我们通过文件 IO 介绍各种标准 IO 函数。首先，打开文件需要使用 `fopen`

```c
FILE* fopen(char const path[static 1], char const mode[static 1]);
```

`fopen` 函数接收两个参数：第一个参数是一个字符串表示需要打开文件的路径；第二个参数也是一个字符串表示打开文件的模式

> [!TIP]
>
> 文件模式由模式和修饰符组成；分别有 $3$ zhong

文件模式：

模式  含义  文件状态
────  ────  ────────────────────
"r"   读    文件不变，定位在开头
"w"   写    文件内容清空
"a"   追加  文件不变，定位在末尾
"r+"  读写  文件不变，定位在开头
"w+"  读写  文件内容清空
"a+"  读写  文件不变，定位在末尾

修饰符：

• "b"：二进制模式
• "x"：独占创建（文件已存在则报错）

```c
FILE* logfile = fopen("mylog.txt", "a");
// 打开文件可能失败，必须检查返回值是否不会 nullptr
if (!logfile) {
    perror("fopen failed");
    return EXIT_FAILURE;
}
fputs("feeling fine today\n", logfile);
```





### 字符输入输出

```c
// 字符输入
int fgetc(FILE* stream);
int getc(FILE* stream)
int getchar(void);
int ungetc(int c, FILE* stream); // 将字符 c 放回 stream 流（放回到下一个shu）

// 字符输出
int fputc(int c, FILE* stream);
int putc(int c, FILE* stream);
int putchar(int c);
```

函数 `fgetc` 和 `getc` 从指定的 `stream` 中读取一个字符；函数  `ungetc` 则是将字符放回指定的 `stream` 中。函数 `fputc` 和 `putc` 向指定的 `stream` 中写入字符 `c`

> [!WARNING]
>
> `int` 类型作为这些函数的参数和返回值是一个历史性事件，它们不会有太大的伤害。与此相反，具有 `int` 类型的返回，可以使函数将错误返回给调用方。特别是，如果成功，它将返回参数 `c` 以及一个特定的负值 `EOF`（End Of File，文件结束），该值确保在失败时不与任何字符相对应。
