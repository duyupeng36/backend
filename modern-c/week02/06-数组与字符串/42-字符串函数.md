# 字符串函数

> week02 · C 语言全貌 · 知识点 42

> 状态：☑ 已完成

---

## 速览

`<string.h>` 提供两组函数：`mem` 系列操作字符数组（`memcpy`/`memcmp`/`memchr`），`str` 系列操作字符串（`strlen`/`strcpy`/`strcmp` 等）。使用字符串函数处理非字符串会导致程序失败。

---

## 是什么

字符串函数是 `<string.h>` 提供的用于操作字符串和字符数组的函数。以 `mem` 开头的函数操作字符数组，以 `str` 开头的函数操作字符串（以 `\0` 结尾）

---

## 详细解释

下标列出了《Modern C》中介绍了的几个重要的函数：前 $3$ 个是 `mem` 开头的系列的函数，它们用于操作字符数组；后面全是 `str` 开头的系列函数，它们用于操作字符串

| 函数                     | 功能     | 说明                                       |
| ----------------------------- | -------- | ------------------------------------------ |
| `memcpy(target, source, len)` | 复制数组 | 必须确保源 `source` 和目标 `target` 不重叠 |
| `memcmp(s0, s1, len) `        | 比较数组 | 字典序比较，返回差值                       |
| `memchr(s, c, len) `          | 查找字符 | 在数组中搜索字符 `c`                       |
| `strlen(s)`               | 计算长度   | 返回 `\0` 之前的位置               |
| `strcpy(target, source) ` | 复制字符串 | target 必须足够大                  |
| `strdup(source)`          | 复制并分配 | 复制并分配  C23 引入，自动分配内存 |
| `strcmp(s0, s1)`          | 比较字符串 | 字典序比较，遇 `\0` 停止           |
| `strcoll(s0, s1)`         | 本地化比较 | 考虑语言环境设置                   |
| `strchr(s, c) `           | 查找字符   | 在字符串中搜索字符 c               |
| `strspn(s0, s1) `         | 计算前缀   | `s0` 开头属于 `s1` 的字符数        |
| `strcspn(s0, s1)`         | 计算前缀   | `s0` 开头不属于 `s1` 的字符数      |

> [!WARNING]
>
> 使用字符串函数（`str`开头的系列函数）处理非字符串会导致程序失败
>
> + `strlen` 等扫描函数执行时间过长（找不到 `\0`）
> + 段错误（访问数组边界外的元素）
> + 看似随机的数据损坏，因为函数将数据写入不该写入的地方

对于字符串函数，它们的函数原型如下：

```c
size_t strlen(char const s[static 1]);
char* strcpy(char target[static 1], char const source[static 1]);
char* strdup(char const s[static 1]);
char* strndup(char const s[static 1], size_t n);
signed strcmp(char const s0[static 1], char const s1[static 1]);
signed strcoll(char const s0[static 1], char const s1[static 1]);
char* strchr(const char s[static 1], int c);
size_t strspn(const char s1[static 1], const char s2[static 1]);
size_t strcspn(const char s1[static 1], const char s2[static 1]);
```

除了 `strcpy`、`strchr`、`strdup` 和 `strndup` 的奇怪返回类型之外，这看起来是合理的。参数数组是未知长度的数组，因此 `[static 1]` 对应于至少一个 `char` 的数组。`strlen`、`strspn` 和 `strcspn` 将返回一个大小，`strcmp` 将根据参数的排序顺序返回负值、0 或正值。

数组函数的声明时，情况更加复杂：这里 `void*` 类型是指向类型为止的对象；我们将在 [数组与指针](43-数组与指针) 介绍它

```c
void* memcpy(void* target, void const* source, size_t len);
signed memcmp(void const* s0, void const* s1, size_t len);
void* memchr(const void *s, int c, size_t n);
```

## 代码示例

```c
#include <string.h>
#include <stdio.h>
int main(int argc, char* argv[argc+1]) {
    size_t const len = strlen(argv[0]);  // 计算长度
    char name[len+1] = { };              // 初始化 VLA
    memcpy(name, argv[0], len);          // 复制数组
    if (!strcmp(name, argv[0])) {         // 比较字符串
        printf("program name \"%s\" successfully copied\n", name);
    } else {
        printf("copying %s leads to different string %s\n", argv[0], name);
    }
}
```

> [!TIP]
>
> 注意：这里 `char name[len+1] = { };` 是变长数组的默认初始化器，这是允许的；不允许是这样的 `= {1, 2, 3}` 显示初始化器
