## 速览

函数是代码复用的基本单元，由返回类型、函数名、参数列表和函数体组成

---

## 是什么

函数是代码复用的基本单元，通过封装特定功能避免重复代码，提供清晰的接口（参数和返回类型），并支持模块化编程。换句话说，函数是命名的程序块

---

## 详细解释

我们已经使用了很多函数（`printf` `scanf` 和 `puts`），并看到了它们的一些声明。在所有这些函数中，圆括号 `()` 都起着重要的语法作用

+ 函数声明和定义时，圆括号 `()` 用来封装参数列表
+ 对于函数调用，圆括号保存具体调用的参数列表

>  [!TIP]
>
> 函数的 `()` 的语法角色类似于数组的 `[]`：在声明和定义中，它们包含相应维度的大小。像 `A[i]` 这样的命名，它们用于指示数组中被访问元素的位置

### 函数原型

我们目前接触到的所有函数都有一个**原型**：原型为函数调用提供了完整的描述

+ 需要提供多少个实际参数
+ 参数应该是什么类型
+ 返回的结果是什么类型

也就是说，函数原型描述了调用函数时需要提供多少个参数，每个参数的类型是什么以及函数返回值的类型。从 C23 标准开始，**所有的函数都必须有原型**；换句话说，C23 标准彻底移除了老式的函数声明（圆括号中没有参数列表）。下面对比了几个旧标准与 C23 标准中函数声明的含义

| 形式                   | 旧标准（C11及以前）含义        | C23 标准中的状态                      |
| ---------------------- | ------------------------------ | ------------------------------------- |
| `int func();`          | 未知参数列表（不进行参数检查） | 视为等同于 `int func(void)`（无参数） |
| `int func(void);`      | 明确无参数                     | 完全合法且推荐                        |
| `int func(int, char);` | 完整函数原型                   | 完全合法且标准                        |

我们来看一个函数的定义

```c
// 函数定义
bool leapyear(unsigned year) {
    return !(year % 4) && ((year % 100) || !(year % 400));
}
// 函数声明（原型）
bool leapyear(unsigned year);
// 省略参数名
extern bool leapyear(unsigned);
```

> [!WARNING]
>
> 注意：如果函数不需要参数，请在参数列表中明确写上 `void` 强调该函数不需要参数，从而保证函数具有原型
>
> ```c
> // 无参数：使用 void
> int main(void) { ... }
> ```
>
> `void` 关键字的另一个用途就是标记函数没有返回值
>
> ```c
> // 无返回值：使用 void
> void swap_double(double *a, double *b) { ... }
> ```

函数原型帮助帮助编译器在需要调用函数的地方知道函数的返回值和期望的参数；至于函数的定义可以放在函数调用之后进行。这是我们能够分文件编程的基础

### 返回值

语句 `return` 用于从函数中返回；任何返回类型非 `void` 的函数的 `return` 语句都必须包含一个表达式；`void` 函数的 `return` 语句则不能包含表达式。

> [!WARNING]
>
> 注意：函数只有一个入口，但可以有多个 `return`。函数中的所有返回值的类型必须与函数声明一致，或者至少可以隐式转换为声明的返回类型。如果到达函数块 `{}` 的末尾都没有遇见 `return` 语句，则相当于没有表达式的 `return` 语句

```c
// 多个 return
int abs_val(int x) {
    if (x < 0) return -x;
    return x;
}

// void 函数可以省略 return
void print_hello(void) {
    printf("Hello\n");
    // 等价于 return;
}
```

### 传值语义（Pass-by-Value）

在 [语句](../../week01/02-程序结构/07-语句.md) 中我们已经介绍过，C 语言函数参数采用**传值语义**：调用函数时，实参的值被复制到形参中，形参是实参的副本。

```c
void increment(int x) {
    x++;  // 修改的是副本，不影响原始值
}

int main(void) {
    int a = 5;
    increment(a);
    printf("a = %d\n", a);  // 输出 5，不是 6
}
```

> [!TIP]
>
> 函数内修改的是实参的副本，不影响实际的参数值

如果想通过函数修改外部变量，需要传递指针：

```c
void increment(int *x) {
    (*x)++;  // 通过指针修改原始值
}

int main(void) {
    int a = 5;
    increment(&a);
    printf("a = %d\n", a);  // 输出 6
}
```

数组作为参数时会退化为指针，因此可以修改原数组：

```c
void modify(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] *= 2;  // 直接修改原数组
    }
}

int main(void) {
    int nums[] = {1, 2, 3};
    modify(nums, 3);
    // nums 现在是 {2, 4, 6}
}
```

下表列出了不同类型传值的方式，以及是否能修改实际参数的值

| 参数类型 | 传递方式 | 能否修改原值 |
|----------|----------|--------------|
| 基本类型（int, double 等） | 传值 | ✗ |
| 指针 | 传指针的值 | ✓（通过解引用） |
| 数组 | 退化为指针 | ✓ |
