## 📋 速览

C 的表达式由操作数和运算符组成，运算符按操作对象分为值运算符、对象运算符和类型运算符三类。表达式计算围绕 `size_t` 展开——无符号算术总是良定义的：溢出时回绕（模 `SIZE_MAX+1`），`/` 和 `%` 不可能溢出。

比较运算符返回 0 或 1，结果可直接参与算术或作为数组索引——一行替代分支。`&&` `||` `?:` 具有短路求值特性，只执行被选中的操作数。`++`/`--` 有前缀后缀之分，副作用应受控：一条语句最多修改一个对象。大多数运算符不保证求值顺序，表达式中的函数调用不应有副作用

## 📖 知识点

### 知识点 1：表达式

**是什么**

表达式（expression）是一段 *计算值* 的代码；它根据其他值算出另一个值。表达式由 *操作数* 和 *运算符* 组成（运算符可以没有）

**详细解释**

我们将围绕 `size_t` 类型展开学习 C 中的表达式。`size_t` 的值域范围是 `[0, SIZE_MAX]`，`SIZE_MAX` 的大小取决于具体平台

| 平台        | `SIZE_MAX` 的值               |
| ----------- | ----------------------------- |
| $16$ 位平台 | $2^{16}-1=65535$              |
| $32$ 位平台 | $2^{32}-1$ 大约是 $43$ 亿     |
| $64$ 位平台 | $2^{64}-1$ 大约是 $1844$ 亿亿 |

> [!TIP]
>
> 不需要记忆，也不需要自行计算 `SIZE_MAX` 的值。C 标准头文件 `<stdint.h>` 中提供了 `SIZE_MAX` 宏
>
> `size_t` 类型属于 C 的无符号整数类型；意味着 **`size_t` 类型的值永远不会小于 $0$**。这个原则很重要

> **`size_t` 类型表示 `[0, SIZE_MAX]` 范围内的值。**

**操作数与运算符**：C 把计算拆分成两个角色：操作数（operand）是被操作的东西，运算符（operator）是执行操作的符号。例如 `a + b` 中，`a` 和 `b` 是操作数，`+` 是运算符。C 的运算符按操作实体可以分为 $3$ 类

| 类型       | 操作对象                 | 举例                              |
| ---------- | ------------------------ | --------------------------------- |
| 值运算符   | 操作值，算出新值         | `+` `-` `*` `/` `%` `==` `!` `&&` |
| 对象运算符 | 操作对象本身，可能改变它 | `=` `+=` `++` `--` `&`            |
| 类型运算符 | 操作类型，返回大小/对齐  | `sizeof ` `alignof`               |

> 这些运算符在后面的 附录 中列出来了。我们不需要记忆它们；在学习过程中自然会记住的

**代码示例**

```c
/* 查看 size_t 的范围和 sizeof */
#include <stdint.h>
#include <stdio.h>

int main(void) {
    printf("size_t 字节数: %zu\n", sizeof(size_t));
    printf("SIZE_MAX = %zu\n", SIZE_MAX);
    // 64位平台输出: size_t 字节数: 8
    //              SIZE_MAX = 18446744073709551615
}
```

### 知识点 2：算术运算 — `+` `-` `*` `/` `%`

**是什么**

C 提供了 $5$ 个执行算术运算的运算符：

| 运算符  | 描述                                 |
| ------- | ------------------------------------ |
| `a + b` | 执行加法运算，获得 `a` 加上 `b` 的和 |
| `a - b` | 执行减法运算，获得 `a` 减去 `b` 的差 |
| `a * b` | 执行乘法运算，获得 `a` 乘以 `b` 的积 |
| `a / b` | 执行除法运算，获得 `a` 除以 `b` 的商 |
| `a % b` | 执行模运算，获得 `a` 除以 `b` 的余数 |

**详细解释**

这些运算符的运算符工作方式与数学上大致相同。这些运算符都需要两个操作数，被称为 **二元运算符**。对于 `+` 和 `-`，它们还有 **一元** 形式的变体：`-b` 对 `b` 的值取负数，`+a` 就是 `a` 本身。此外，值得额外探讨的算术运算符就是 **除法和取模**

> [!TIP]
>
> **整数除法**：当运算符 `/` 的两个操作数都是整数时，执行整数除法：表达式 `a / b` 计算的是 `b` 能够放进 `a` 多少次，余数部分直接丢弃。运算符 `%` 是对整数除法的补充：提供了获取整数除法中余数的方法。因此，表达式 `a == (a / b) * b + (a % b)` 一定是成立。用数学公式表示为
> $$
> a = \left\lfloor \frac{a}{b} \right\rfloor \times b + a \bmod b
> $$
> 整数除法有一个绝对禁区：右操作数(`b`)不能是 $0$。除以 $0$ 在 C 中是未定义行为，程序可能直接崩溃

> **对于无符号值，`a == (a/b)*b + (a%b)` 恒成立。**
>
> **无符号 `/` 和 `%` 仅在第二个操作数不为 0 时才良定义。**

**代码示例**

《Modern C》中的示例代码片段：

```c
size_t a = 45;
size_t b = 7;
size_t c = (a - b) * 2;   // (45-7)*2 = 76
size_t d = a - b * 2;      // 45-14 = 31  乘除优先级高于加减
```

这里 `c` 的值一定是 $76$，`d` 的值是 $31$。圆括号用于分组子表达式，以强制运算符优先绑定的操作数。

### 知识点 3：无符号溢出与回绕

**是什么**

无符号整数的算术运算总是定义良好的。当运算结果超出类型能够存储的最大值时，C 语言会 **回绕**：本质上就是对真实结果进行了一次取模运算

**详细解释**

对于无符号类型 `size_t`，算术运算符总是定义良好的，计算发生溢出也可以确定溢出后的值：无符号整数的算术运算符本质上就是在 `SIZE_MAX + 1` 中进行 **回绕**：对于无符号整数 `a` 和 `b`，任何算术运算的结果都是对 `SIZE_MAX + 1` 取模后的结果；即 `a op b = (a op b) % (SIZE_MAX + 1)`。用数学方式表示为
$$
a\ \text{op}\ b = (a\ \text{op}\ b) \bmod {\text{SIZE\_MAX} + 1}
$$
由于无符号算术的回绕机制，任何算术运算符在无符号整数上都有良好的定义

> [!TIP]
>
> 运算符 `/` 和 `%` 操作的结果一定会小于操作数。因此，它们的计算结果一定不可能出现溢出情形

> **`size_t` 上的算术隐式地计算模 `SIZE_MAX + 1`；发生溢出时回绕。**
>
> **无符号 `/` 和 `%` 的结果总是小于操作数，不可能溢出。**

**代码示例**

```c
/* 演示无符号溢出回绕 */
#include <stdint.h>
#include <stdio.h>

int main(void) {
    size_t a = SIZE_MAX;
    printf("SIZE_MAX + 1 = %zu\n", a + 1);   // 输出 0

    size_t b = 0;
    printf("0 - 1 = %zu\n", b - 1);           // 输出 SIZE_MAX

    // 溢出等价于取模
    printf("(SIZE_MAX + 1) %% (SIZE_MAX + 1) = %zu\n",
           (SIZE_MAX + 1) % (SIZE_MAX + 1));  // 编译器可能警告，但结果正确
}
```

### 知识点 4：修改对象的运算符 — 赋值、`++`/`--`、复合赋值

**是什么**

算术运算符是值运算符，它们只是读取操作数并计算出新的值，操作数本身不会被修改。而修改对象的运算符不一样：它们直接修改对象本身

**详细解释**

**赋值与复合赋值**：运算符 `=` 用于赋值（前面我们已经见过了）；它的左操作数必须是一个**可寻址的对象**（能写入的内存）；右操作数是值。在 C 语言中，赋值也是一个表达式，其值就是将修改后对象的值。下面的表达式在 C 中是合法的

```c
a = b = 42; // 在 C 中是合法的
```

这表达式首先将 `42` 赋值给 `b`，然后将 `b = 42` 的值赋值给 `a`。它等价于 `a = (b = 43)` 

赋值表达式还可以与算术运算符组合使用，即 `op=`（中间不允许有空格）；表达式 `a op= b` 等价于 `a = a op (b)` 

```c
a += 7;  	// 等价于 a = a + 7
a *= 2;  	// 等价于 a = a * 2
a /= c + 2; // 等价于 a = a / (c + 2)
```

> [!WARNING]
>
> 注意，复合赋值运算符右侧一点要先计算出值，然后才能执行运算符。换句话说，`a = a op (b)` 中的圆括号 `(b)` 是不可以被省略的

变量自增(`+1`) 和递减(`-1`) 在 C 语言非常常用，C 为此定义了两个运算符 `++` 和 `--`；它们可以用作前缀运算符和后缀运算

+ 表达式 `++i` 的值是加 $1$ 后的值(`i + 1`)
+ 表达式 `i--` 的值是减 $1$ 前的值(`i`)

> 无论如何 `++` 和 `--` 始终会修改对象的值(对操作数的影响是相同的)。但是，我们始终建议用作前缀；因为 `++i` 不会产生临时对象，直接就修改变量 `i` 的值；而 `i++` 会产生一个临时对象（现代编译器可能优化掉这个操作）

还有一点需要注意：有其他运算符与 `++` 混合使用时，应该非常小心

```c
size_t a = 5;
size_t b = ++a;   // a 先变 6，b = 6
size_t c = a++;   // c 先拿旧值 6，然后 a 变 7
```

> [!WARNING]
>
> 必须遵守一个原则：**同一个表达式中，最多修改一个对象**；表达式中修改对象（副作用）会让代码出现难以预测
>
> 不要再一个表达式中出现多个修改对象的代码；例如，`a = b = c += ++d`。虽然 C 标准没有禁止这种操作，但是一定不要这样写
>
> + **可读性为零**——没人一眼能看出最终值
> + **求值顺序不确定**——不同编译器可能给出不同结果

**代码示例**

```c
/* object_ops.c — 对象运算符演示 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    size_t a = 10;

    // 赋值
    size_t b = a;          // b = 10

    // 复合赋值
    a += 5;                // a = 15
    a *= 2;                // a = 30
    a %= 7;                // a = 2  (30 % 7)

    // 前缀 ++：先加后用
    size_t c = ++a;        // a = 3, c = 3

    // 后缀 ++：先用后加
    size_t d = a++;        // d = 3, a = 4

    printf("a=%zu, b=%zu, c=%zu, d=%zu\n", a, b, c, d);
    // 输出: a=4, b=10, c=3, d=3

    return EXIT_SUCCESS;
}
```

### 知识点 5：比较运算符与布尔语境

**是什么**

比较运算符是用于比较两个值，其操作结果是逻辑值。

**详细解释**

C 提供了六个比较运算符；但是，C 的核心准则 **数值即真值**，这六个比较运算符的操作结果仍然是数字

> [!TIP]
>
> 在 C 中，比较运算符返回的不是 "真" 或 "假" 这两个抽象的概念，而返回的是数字 $1$ 或 $0$；

```c
a == b;  // a 和 b 的值相等，这个表达式的值是 1；否则，该表达式的值是 0
a < b;   // a 小于 b 时，这个表达式的值时 1；其他情况都是 0
```

既然如此；比较结果可以出现在任何整数可以出现的地方。例如，参与算术运算和作为数组的索引

```c
size_t c = (a < b) + (a == b) + (a > b); // c 的值一定是 1（a 和 b 一定会曼满足其中一个条件）

double largeA[N] = { ... };
size_t sign[2] = { 0, 0 };
for (size_t i = 0; i < N; ++i) {
    sign[(largeA[i] < 1.0)] += 1;   // true(1) 或 false(0) 直接当索引
}
// sign[0] = 大于等于 1.0 的数量
// sign[1] = 严格小于 1.0 的数量
```

> 表达式 `sign[(largeA[i] < 1.0)] += 1;` 只使用了一行就做到了 `if` 语句先判断后累加才能作为的结果

**代码示例**

```c
/* compare.c — 比较结果作为数字使用 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // 比较结果即 0 或 1
    printf("5 < 3  = %d\n", 5 < 3);     // 0
    printf("5 > 3  = %d\n", 5 > 3);     // 1
    printf("5 == 5 = %d\n", 5 == 5);    // 1

    // 三个关系之和一定为 1
    size_t a = 7, b = 7;
    printf("(a<b)+(a==b)+(a>b) = %zu\n",
           (a < b) + (a == b) + (a > b));  // 1

    // 用比较结果做数组索引统计
    double arr[] = {0.5, 2.0, 0.3, 1.5, 0.8};
    size_t count[2] = {0, 0};
    for (size_t i = 0; i < 5; ++i) {
        count[(arr[i] >= 1.0)] += 1;
    }
    printf("< 1.0: %zu, >= 1.0: %zu\n",
           count[0], count[1]);  // < 1.0: 3, >= 1.0: 2

    return EXIT_SUCCESS;
}
```

### 知识点 6：逻辑运算符与短路求值

**是什么**

逻辑运算符是用来连接多个条件并判断它们真假的符号。因此，逻辑运算符作用于那些已经被假定表示 `false` 或 `true` （即：`0` 或 `1`）的值

**详细解释**

C 语言提供了 $3$ 个逻辑运算符：`!`(非)、`&&`(与)、`||`(或)。它们操作真值（0 或非 0），同时返回的也是真值（0 或 1）。下表列出了

| `a`     | `!a`    | `a && b`<br />(`b` 为 `true`) | `a && b`<br />(`b` 为 `false`) | `a || b` <br />(`b` 为 `true`) | `a && b`<br />(`b` 为 `false`) |
| ------- | ------- | ----------------------------- | ------------------------------ | ------------------------------ | ------------------------------ |
| `false` | `true`  | `false`                       | `false`                        | `true`                         | `false`                        |
| `true`  | `false` | `true`                        | `false`                        | `true`                         | `true`                         |

>  [!TIP]
>
> 这表总结起来就: `&&` 两边都真才真，`||` 一边真就真，`!` 对逻辑值取反

**`&&` 和 `||` 短路特性**：运算符 `&&` 和 `||` 的左操作数已经能确定结果，右操作数根部就会进行计算。下面的代码片段演示了这个特性

```c
if (b != 0 && (a / b) > 1) {  // b=0 时，(a/b) 永远不会执行
	++x;
}

// 等价于
if (b) {
    if (a / b > 1) ++x;
}
```

`b != 0` 为假时，由 `&&` 构成的表达式一定是假，C 直接跳过右边的 `a / b`。因此，永远不会出现除零的情况。同理，由 `!!` 构成的表达式的左操作数为真时，C 也会跳过右操作数的计算。

> [!TIP]
>
> 双重否定 `!!`: `!!x` 进行两次取反，其作用就是把任意值标准化为 $0$ 或 $1$
>
> ```c
> double largeA[N] = { ... };
> size_t isset[2] = { 0, 0 };
> for (size_t i = 0; i < N; ++i) {
>     isset[!!largeA[i]] += 1;   // !!x: 非零→1, 零→0
> }
> // isset[0] = 0.0 的个数
> // isset[1] = 非零的个数（不仅仅是 1.0）
> ```

**代码示例**

```c
/* logic.c — 逻辑运算符和短路求值 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // 短路求值：第二个操作数可能不执行
    int a = 0;
    printf("a && ++a: %d, a=%d\n", a && ++a, a);   // 0, a=0 (++a 没执行)

    a = 1;
    printf("a || ++a: %d, a=%d\n", a || ++a, a);    // 1, a=1 (++a 没执行)

    // 双重否定：标准化为 0 或 1
    printf("!!0   = %d\n", !!0);     // 0
    printf("!!42  = %d\n", !!42);    // 1
    printf("!!-1  = %d\n", !!-1);    // 1

    return EXIT_SUCCESS;
}
```

### 知识点 7：三元运算符 `?:` 与求值顺序

**是什么**

三元运算符需要三个操作数，C 只有一个三元运算符 `? :`，它本质上是简单 `if-else` 语句的表达式形式 

一个表达式可以被分解成多个子表达式。C 标准并没有规定这些子表达式必须从左向右（或从右向左）进行计算。只有少部分运算符有求值顺序的限制

**详细解释**

三元运算符 `? :` 需要三个操作，分别位于这两个符号的两边：`condition ? true-expression : false-expression`

+ 当 `condition` 的值为 `true(1)` 时，表达式的值就是 `true-expression` 表达式的值
+ 当 `condition` 的值为 `false(0)` 时，表达式的值就是 `false-expression` 表达式的值

```c
size_t size_min(size_t a, size_t b) {
    return (a < b) ? a : b;   // 如果 a<b，返回 a；否则返回 b
}
```

> [!TIP]
> 与 `&&` 和 `||` 一样，运算符 `?:` 也具有短路特性: *只执行被选中的那个分支*
>
> ```c
> b != 0 ? (a / b) : 0; // b = 0 时，a / b 不会执行 
> ```

运算符 `&&` `||` 和 `?:` 都是 C 中少数几个**保证求值顺序**的运算符。其他大多数运算符（比如 `f(a) + g(b)`）的执行顺序是不确定的。

另一个保证求值顺序的运算符是逗号运算符（`,`），已经在 `for` 语句中见过它。这里补充说明一点：逗号运算符连接的所有子表达式按顺序从左到右进行计算，最后一个子表达式的值就是逗号运算符返回的值

> [!WARNING]
>
> 在表达式 `f(a) + g(b)` 中，`f` 和 `g` 谁先执行取决于编译器。如果 `f` 或 `g` 有副作用（修改外部变量），结果不可预测。因此，表达式必须遵守的铁律：**表达式中的函数调用不应该有副作用**

**代码示例**

```c
/* ternary.c — 三元运算符演示 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int a = 10, b = 20;

    // 基本用法：替代简单的 if-else
    int max = (a > b) ? a : b;
    printf("max(%d, %d) = %d\n", a, b, max);  // 20

    // 嵌套使用：三个数求最大
    int c = 15;
    int max3 = (a > b) ? ((a > c) ? a : c)
                       : ((b > c) ? b : c);
    printf("max(%d, %d, %d) = %d\n", a, b, c, max3);  // 20

    // 短路：未选中的分支不执行
    int x = 0;
    int safe = (x != 0) ? (100 / x) : -1;
    printf("safe = %d\n", safe);  // -1, 不会除零

    return EXIT_SUCCESS;
}
```
