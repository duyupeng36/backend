## 📋 速览

C 语言是命令式、编译型语言。程序从 `main` 函数开始，通过 `printf` 输出。源码必须经编译器翻译为机器码才能运行。编译时加 `-Wall` 启用警告，零警告才算干净程序。编译器是朋友——每个警告背后都可能是一个 `bug`。
