## 📋 速览

C 程序由**六种基本词法元素**（特殊词、标点、注释、字面量、标识符、运算符）按语法规则组合而成。理解 C 程序需要区分三个语义层面：

1. **声明** — 告诉编译器标识符代表什么（类型+名字）。所有标识符必须先声明后使用。声明有作用域（文件作用域、块作用域）。
2. **定义** — 声明 + 初始化器（或函数体）= 定义，创建实体并分配存储。每个对象/函数必须恰好有一个定义。
3. **语句** — 执行单元。三种基本类型：迭代（`for`）、函数调用（传值调用）、返回（`return`）。

关键区分：**声明**只描述，**定义**创建实体，**语句**执行动作。

## 📖 知识点

### 知识点 1：语法（Grammar）

**是什么**

构成 C 程序的是一系列不同类型的**文本元素**，它们按照某种**规则**组合在一起；组合这些文本元素的规则称为 **语法**。C 程序文本元素可以分为**六种基本构件**

**详细解释**

1. 特殊词：它们是 C 语言内部使用。不能修改，不能用作自己的名字；这些特殊词又被分为几类。在 `getting-started.c` 中我们使用的特殊词包括（关键字、属性、标准保留标识符、预处理指令）：

    ```c
    // 关键字：
    int;
    double;
    char;
    for;
    return;
    // 属性(C23 新增，放在双方括号中)
    [[maybe_unused]]
    // C标准保留标识符
    size_t;
    EXIT_SUCCESS;
    // 预处理指令
    #include;
    ```

2. 标点：使用 $6$ 种括号和 $2$ 种分隔符组织程序文本的结构

    | 括号      | 使用示例                                                     |
    | --------- | ------------------------------------------------------------ |
    | `{}`      | 函数体、for循环体、初始列表                                  |
    | `()`      | 函数调用(`printf()`)和函数声明(`int main(....)`)、``for (...)` 的条件 |
    | `[]`      | 数组声明(`double A[5]`)和数组索引(`A[i]`)、指定初始化(`[0] = 9.0`) |
    | `[[]]`    | 属性(`[[maybe_unused]]`)                                     |
    | `/*...*/` | 注释(`/* This may look like nonsense, but really is -*- mode: C -*- */`) |
    | `<...>`   | 仅用于头文件包含 `#include <stdio.h>`                        |

    括号使用规则：括号必须成对出现；除了 `<...>` 以外，其他 $5$ 个括号均可以跨行。**同一个标点可能用于不同的用途**（C 语言的一个难点之一）

    | 分隔符 | 使用示例                                                     |
    | ------ | ------------------------------------------------------------ |
    | `;`    | 语句终结符号：每条语句必须以分号结尾(`printf(...);`)         |
    | `,`    | 参数分隔符(`printf("...", i, A[i], A[i] * A[i])`) 和 列表元素分隔符(`{[0] = 9.0, [1] = 2.9}`) |

3. 注释：写给人类程序员看的，用于解释代码意图
    C 标准规定了两种形式的注释：**传统注释（块注释）** 和 **C++风格注释（行注释）**

    ```c
    /* 传统注释，可以跨多行 */
    
    // C++ 风格注释，从 // 到行尾结束
    ```

    编译器会完全忽略注释的内容；换句话说，注释是写给人程序员看到。**注释是解释代码意图的好地方**

4. 字面量：直接写在代码中的固定值
    在 C 源码中直接表示**固定值**。编译器会将字面量整合到最终的可执行文件中，程序运行时保证不变。并且，字面量存在类型这一个概念

    ```c
    0, 1, 5                  // 整数字面量
    9.0, 2.9, 3.E+25, .00007 // 浮点数字面量
    "element %zu is %g, \tits square is %g\n"  // 字符串字面量
    ```

5. 标识符：人类程序员给程序中各种实体起的名字。标识符在程序中可以扮演不同的角色

    | 角色                       | 描述                                                         |
    | -------------------------- | ------------------------------------------------------------ |
    | 数据对象（也称为**变量**） | 运行环境中的内存块，其中的内容可以表示值。例如，标识符 `A` 和 `i` |
    | 类型别名                   | 新对象的种类。例如 `size_t`（末尾`_t`是C标准的命名约定，提示它是类型） |
    | 函数                       | 命名的代码片段。例如 `main` 和 `printf`                      |
    | 常量                       | 运行时不能修改的对象。例如 `EXIT_SUCCESS`                    |

6. 运算符：C 程序用来对值/对象/类型进行操作的符号。接收一个或多个输入并产生一个输出值
    **运算符**是C语言预定义的基本操作通常可以与机器指令一一对应。在示例程序 `getting-started.c` 中，我们只用到了少数几个

    | 运算符 | 含义           | 例子                  |
    | ------ | -------------- | --------------------- |
    | `=`    | 初始化 / 赋值  | `double A[5] = {...}` |
    | `<`    | 小于比较       | `i < 5`               |
    | `++`   | 自增（值加 1） | `++i`                 |
    | `*`    | 乘法           | `A[i] * A[i]`         |



使用这六种基本的 C 程序构件可以组合出其他 C 程序实体。**函数** 就是由这些基本构件组成的。例如

```c
int main(int argc, [[maybe_unused]]char* argv[argc + 1]) {
    ...
}
```

标识符 `main` 扮演了**函数**这一角色；它完全由上述六种基本程序构件组合而成。`{...}` 中的内容称为 **函数体**，包含了函数需要执行所有语句。`main` 函数非常特殊，**它是托管环境中 C 程序的执行入口**；每一个在托管环境中执行的 C 程序必须有且只有一个 `main` 函数

**属性**（C23 标准引入） 是由标识符和标点`[[]]`组合而成，为程序的基本结构提供一些补充信息，例如 `[[maybe_unused]]`

### 知识点 2：声明（Declarations）

**是什么**

在 C 程序中，使用某个标识符之前，我们必须给编译器一个 **声明**，指明该标识符应该代表什么(扮演什么样的角色)

**详细解释**

使用标识符之前必须先声明；它是给编译器的承诺：存在一个程序实体，它的名字是什么以及扮演什么样的角色。C 程序中的每条声明都遵循相同的模式： **类型 + 标识符**。例如，在示例程序 `getting-started.c` 中的几个标识符声明

| 声明                     | 类型                | 标识符 | 角色                                  |
| ------------------------ | ------------------- | ------ | ------------------------------------- |
| `int main(int, char[]) ` | `int (int, char[])` | `main` | 标识符后`(...)`表示该标识符代表函数   |
| `int argc`               | `int`               | `argc` | 数据对象（变量）                      |
| `double A[5]`            | `double[5]`         | `A`    | 标识符后 `[...]` 表示该标识符代表数组 |
| `size_t i`               | `size_t`            | `i`    | 数据对象                              |
| `char argv[]`            | `char*`             | `argv` | 数组型参数(蜕化为指针)                |

声明只是告诉编译器某个标识符代表什么，并不创建实体。只要将声明中的标识符去掉，就能很容易看出这个标识符扮演了什么角色了。上表中的类型列显示的就是标识符扮演的角色(标识符的**类型**)。类型决定了标识符在表达式中能提供什么样的值

**作用域与重复声明**

同一个标识符可以有多个一致的声明（声明不创建程序实体，重复声明除了带来冗余以外没有其他危害），但是**相同作用域内不能有矛盾的声明**

每个标识符的声明都有它可见的范围，这个范围称为**作用域**。超出作用域，标识符就不可见了。示例程序 `getting-started.c` 中有 $4$ 层嵌套的作用域

```shell
文件作用域 (file scope)            			   ← main、printf、size_t 在此
  └── main 函数体 (block scope)    			← A、argc、argv 在此
       └── for 的声明部分 (primary block)
            └── for 的循环体 (secondary block)  ← i 在此
```

同一个标识符在不同作用域中可以存在不同的声明，内层作用域中的声明将**隐藏**上层作用域的声明。具有**文件作用域**的标识符必须在任何`()` 和 `{}` 之外进行声明，从声明初到文件末尾都是可见的，文件作用域中的标识符通常被称为全局变量；在 `{}` 内声明的标识符具有 **块作用域**，只在声明块内空间。

### 知识点 3：定义（Definitions）

**是什么**

*定义是扩展了的声明*。下表列出了声明与定义之间的区别

| 维度 | 声明（Declaration） | 定义（Definition） |
|--|-------------------|-------------------|
| 做什么 | 告诉编译器标识符代表什么 | 告诉编译器对象在哪里、值是什么 |
| 创建实体？ | ❌ 不创建 | ✅ 创建（分配存储空间） |
| 可以重复？ | ✅ 可以有多个一致声明 | ❌ 每个对象/函数只能有一个 |

**详细解释**

声明是向编译承诺存在一个程序实体，定义就是兑现承诺；即，创建程序实体。对于数据对象就是分配存储空间；函数就是生成函数的指令；类型别名只是创建数据对象的蓝图，仅声明即可。

《Modern C》中的定义被认为是 **声明 + 初始化列表**；换句话说，**定义总是应该伴随初始化**。例如

```c
size_t i = 0;	// 声明 + 初始化 = 定义
```

这行代码告诉编译器标识符 `i` 是 `size_t` 类型的数据对象，并且应该为它分配内存空间并不 $0$ 写入内存空间中

**初始化**：指定初始化

示例程序 `getting-started.c` 中，数组 `A` 初始化称为 **指定初始化**(C99起)。方括号 `[n] = value` 指明数组中索引为 `n` 的元素值为 `value`。任何没有在初始化列表中指定的位置，自动设置为 $0$

`````c
double A[5] = {
    [0] = 9.0,       // 第0个元素 = 9.0
    [1] = 2.9,       // 第1个元素 = 2.9
    [4] = 3.E+25,    // 第4个元素 = 3.E+25
    [3] = .00007,    // 第3个元素 = .00007
};
`````

**数组索引**：数组索引(下标)从 $0$ 开始，`A[0]` 是数组 `A` 的第一个元素，`A[n-1]` 是数组的最后一个元素（共 $n$ 个元素）。索引(下标)可以理解为**元素距离数组起点的偏移量**

**函数定义**：函数定义很简单，只需要在函数声明后跟随 `{...}` 函数体就是函数定义

```c
// 只是声明（后面有分号）
int main(int, char*[]);

// 声明 + {} 函数体 = 定义
int main(int argc, [[maybe_unused]] char* argv[argc + 1]) {
    // ...
}
```

> [!WARNING]
> 数据对象或函数必须有且只有一个定义
> 
> + 没有定义 → 链接器不知道在哪里找它 → 链接错误
> + 多于一个定义 → 链接器不知道该用哪个 → 冲突错误

### 知识点 4：语句（Statements）

**是什么**

语句是 C 程序的基本执行单元，它告诉编译器如何处理已经声明和定义好的标识符

**详细解释**

示例程序 `getting-started.c` 的核心执行部分就是由三种类型的语句组成：**迭代语句**、**函数调用语句**和**返回语句**

```c
for (size_t i = 0; i < 5; ++i) {          // 迭代语句
    printf("element %zu is %g, \tits square is %g\n",
           i,
           A[i],
           A[i]*A[i]);                     // 函数调用语句
}
return EXIT_SUCCESS;                       // 返回语句

```

**迭代语句**：`for` 语句是 C 常用的范围迭代语句，由 $4$ 部分组成

```c
    //   (1)        (2)       (3)  (4)
for (size_t i = 0;  i < 5;    ++i)  {
    // 循环体
}

```

下表列出了 `for` 语句各个部分的执行时机和作用域

| 部分  | 名称     | 执行时机           | 作用                                 |
| ----- | -------- | ------------------ | ------------------------------------ |
| `(1)` | 初始化   | 循环开始前执行一次 | 声明并初始化循环变量 `i`             |
| `(2)` | 循环条件 | 每次迭代前检查     | `i < 5` 为真则执行循环体，为假则结束 |
| `(3)` | 迭代操作 | 每次迭代后执行     | `++i` 将 `i` 加 $1$                  |
| `(4)` | 循环体   | 每次条件为真时执行 | 打印结果                             |

`for` 语句的执行过程如下：`(1) → (2) → (4) → (3) → (2) → (4) → (3) → ...`

```
i = 0 → 检查 0 < 5? 真 → 打印 → ++i → i = 1
      → 检查 1 < 5? 真 → 打印 → ++i → i = 2
      → 检查 2 < 5? 真 → 打印 → ++i → i = 3
      → 检查 3 < 5? 真 → 打印 → ++i → i = 4
      → 检查 4 < 5? 真 → 打印 → ++i → i = 5
      → 检查 5 < 5? 假 → 结束
```

**函数调用**：挂起当前函数，把控制权交给被调用的函数，等它执行完 `return` 后，再回到原来的位置继续执行。例如示例程序 `getting-started.c` 中的 `printf(...)` 就是一个函数调用：`main() ──→ printf() ──→ return ──→ main() 继续`



> [!WARNING]
>
> C 程序中调用函数传递过去的是 **值** 而不是变量本身：`printf` 接收的 `i` 是值 $0$、`A[i]` 是值 `9.0` 、`A[i] * A[i]` 是值 `81.0`。换句话说，`printf` 中无法修改 `i` 和 `A[i]` 的值。这种机制称为 **传值调用**

**函数返回**：`return` 语句结束当前函数的执行，把控制权还给调用者。在 `main` 函数中

```c
return EXIT_SUCCESS; // 返回 EXIT_SUCCESS（通常定义为 0）
```

因为 `main` 的声明类型是 `int`，所以 `return` 必须返回一个 `int` 类型的值。``EXIT_SUCCESS` 表示"程序正常结束"。示例程序 `getting-started.c` 的整个执行流程是

```
系统启动例程 → 调用 main()
                ├── 声明 A 和 i
                ├── for 循环中调用 printf 5 次
                │    每次 printf 内部执行完 return 回来
                └── 执行 return EXIT_SUCCESS → 返回给启动例程 → 程序结束
```
