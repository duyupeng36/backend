**题目 6**【控制语句】：`while` 循环和 `do-while` 循环的核心区别是什么？各举一个适用场景。

+ `while` 语句在执行循环体之前求值
+ `do-while` 语句在执行循环体之后求值

比如，想要计算整数的位数，使用 `do-while`，而不是 `while`。因为，当输入数字是 0 时，也需要进行计算

### 练习 11：最大公约数（10 分钟）【控制语句】

编写程序，输入两个正整数，求它们的最大公约数（GCD）。

**要求**：

- 使用辗转相除法（Euclid 算法）
- 使用 `while` 循环

**示例输出**：

```
请输入两个正整数：48 36
最大公约数：12
```

```c
/* gcd.c - 计算两个数的最大公约数 */
#include <stdio.h>

int main(void) {
    int a = {0};
    int b = {0};
    printf("请输入两个正整数: ");
    scanf("%d%d", &a, &b);

    if (a < b) {
        int temp = a;
        a = b;
        b = temp;
    }

    while (b != 0)
    {
        int r = a % b;
        if (r == 0) {
            break;
        }
        a = b;
        b = r;
    }

    printf("最大公约数是: %d\n", b);
    return 0;
}
```

```c
for (int i = 0; i < 5; i++) {

        }
```
