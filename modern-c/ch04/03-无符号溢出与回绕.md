## 📋 速览

C 的表达式由操作数和运算符组成，运算符按操作对象分为值运算符、对象运算符和类型运算符三类。表达式计算围绕 `size_t` 展开——无符号算术总是良定义的：溢出时回绕（模 `SIZE_MAX+1`），`/` 和 `%` 不可能溢出。

比较运算符返回 0 或 1，结果可直接参与算术或作为数组索引——一行替代分支。`&&` `||` `?:` 具有短路求值特性，只执行被选中的操作数。`++`/`--` 有前缀后缀之分，副作用应受控：一条语句最多修改一个对象。大多数运算符不保证求值顺序，表达式中的函数调用不应有副作用

## 📖 知识点


### 知识点 3：无符号溢出与回绕


**是什么**

无符号整数的算术运算总是定义良好的。当运算结果超出类型能够存储的最大值时，C 语言会 **回绕**：本质上就是对真实结果进行了一次取模运算

**详细解释**

对于无符号类型 `size_t`，算术运算符总是定义良好的，计算发生溢出也可以确定溢出后的值：无符号整数的算术运算符本质上就是在 `SIZE_MAX + 1` 中进行 **回绕**：对于无符号整数 `a` 和 `b`，任何算术运算的结果都是对 `SIZE_MAX + 1` 取模后的结果；即 `a op b = (a op b) % (SIZE_MAX + 1)`。用数学方式表示为
$$
a\ \text{op}\ b = (a\ \text{op}\ b) \bmod {\text{SIZE\_MAX} + 1}
$$
由于无符号算术的回绕机制，任何算术运算符在无符号整数上都有良好的定义

> [!TIP]
>
> 运算符 `/` 和 `%` 操作的结果一定会小于操作数。因此，它们的计算结果一定不可能出现溢出情形

> **`size_t` 上的算术隐式地计算模 `SIZE_MAX + 1`；发生溢出时回绕。**
>
> **无符号 `/` 和 `%` 的结果总是小于操作数，不可能溢出。**

**代码示例**

```c
/* 演示无符号溢出回绕 */
#include <stdint.h>
#include <stdio.h>

int main(void) {
    size_t a = SIZE_MAX;
    printf("SIZE_MAX + 1 = %zu\n", a + 1);   // 输出 0

    size_t b = 0;
    printf("0 - 1 = %zu\n", b - 1);           // 输出 SIZE_MAX

    // 溢出等价于取模
    printf("(SIZE_MAX + 1) %% (SIZE_MAX + 1) = %zu\n",
           (SIZE_MAX + 1) % (SIZE_MAX + 1));  // 编译器可能警告，但结果正确
}
```

- [x] **练习 3**：`/` 和 `%` 不会溢出 — 为什么 `a / b` 和 `a % b` 永远不可能溢出？（提示：考虑它们的结果范围和操作数的关系）
    答案：运算符 `/` 和 `%` 的结果会比所有操作数都小。`a / b` 计算的是 `a` 是 `b` 的几倍，并丢弃余数。最小值一定是 `0`，最大值时 `SIZE_MAX`，显然不会溢出。运算符 `a % b` 计算的是 `a / b` 的余数，显然最小值是 `0`，最大值是 `b - 1`
