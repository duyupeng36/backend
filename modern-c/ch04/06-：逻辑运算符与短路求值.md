## 📋 速览

C 的表达式由操作数和运算符组成，运算符按操作对象分为值运算符、对象运算符和类型运算符三类。表达式计算围绕 `size_t` 展开——无符号算术总是良定义的：溢出时回绕（模 `SIZE_MAX+1`），`/` 和 `%` 不可能溢出。

比较运算符返回 0 或 1，结果可直接参与算术或作为数组索引——一行替代分支。`&&` `||` `?:` 具有短路求值特性，只执行被选中的操作数。`++`/`--` 有前缀后缀之分，副作用应受控：一条语句最多修改一个对象。大多数运算符不保证求值顺序，表达式中的函数调用不应有副作用

## 📖 知识点


### 知识点 6：逻辑运算符与短路求值


**是什么**

逻辑运算符是用来连接多个条件并判断它们真假的符号。因此，逻辑运算符作用于那些已经被假定表示 `false` 或 `true` （即：`0` 或 `1`）的值

**详细解释**

C 语言提供了 $3$ 个逻辑运算符：`!`(非)、`&&`(与)、`||`(或)。它们操作真值（0 或非 0），同时返回的也是真值（0 或 1）。下表列出了

| `a`     | `!a`    | `a && b`<br />(`b` 为 `true`) | `a && b`<br />(`b` 为 `false`) | `a || b` <br />(`b` 为 `true`) | `a && b`<br />(`b` 为 `false`) |
| ------- | ------- | ----------------------------- | ------------------------------ | ------------------------------ | ------------------------------ |
| `false` | `true`  | `false`                       | `false`                        | `true`                         | `false`                        |
| `true`  | `false` | `true`                        | `false`                        | `true`                         | `true`                         |

>  [!TIP]
>
> 这表总结起来就: `&&` 两边都真才真，`||` 一边真就真，`!` 对逻辑值取反

**`&&` 和 `||` 短路特性**：运算符 `&&` 和 `||` 的左操作数已经能确定结果，右操作数根部就会进行计算。下面的代码片段演示了这个特性

```c
if (b != 0 && (a / b) > 1) {  // b=0 时，(a/b) 永远不会执行
	++x;
}

// 等价于
if (b) {
    if (a / b > 1) ++x;
}
```

`b != 0` 为假时，由 `&&` 构成的表达式一定是假，C 直接跳过右边的 `a / b`。因此，永远不会出现除零的情况。同理，由 `!!` 构成的表达式的左操作数为真时，C 也会跳过右操作数的计算。

> [!TIP]
>
> 双重否定 `!!`: `!!x` 进行两次取反，其作用就是把任意值标准化为 $0$ 或 $1$
>
> ```c
> double largeA[N] = { ... };
> size_t isset[2] = { 0, 0 };
> for (size_t i = 0; i < N; ++i) {
>     isset[!!largeA[i]] += 1;   // !!x: 非零→1, 零→0
> }
> // isset[0] = 0.0 的个数
> // isset[1] = 非零的个数（不仅仅是 1.0）
> ```

**代码示例**

```c
/* logic.c — 逻辑运算符和短路求值 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // 短路求值：第二个操作数可能不执行
    int a = 0;
    printf("a && ++a: %d, a=%d\n", a && ++a, a);   // 0, a=0 (++a 没执行)

    a = 1;
    printf("a || ++a: %d, a=%d\n", a || ++a, a);    // 1, a=1 (++a 没执行)

    // 双重否定：标准化为 0 或 1
    printf("!!0   = %d\n", !!0);     // 0
    printf("!!42  = %d\n", !!42);    // 1
    printf("!!-1  = %d\n", !!-1);    // 1

    return EXIT_SUCCESS;
}
```
