## 📋 速览

C 的表达式由操作数和运算符组成，运算符按操作对象分为值运算符、对象运算符和类型运算符三类。表达式计算围绕 `size_t` 展开——无符号算术总是良定义的：溢出时回绕（模 `SIZE_MAX+1`），`/` 和 `%` 不可能溢出。

比较运算符返回 0 或 1，结果可直接参与算术或作为数组索引——一行替代分支。`&&` `||` `?:` 具有短路求值特性，只执行被选中的操作数。`++`/`--` 有前缀后缀之分，副作用应受控：一条语句最多修改一个对象。大多数运算符不保证求值顺序，表达式中的函数调用不应有副作用

## 📖 知识点


### 知识点 5：比较运算符与布尔语境


**是什么**

比较运算符是用于比较两个值，其操作结果是逻辑值。

**详细解释**

C 提供了六个比较运算符；但是，C 的核心准则 **数值即真值**，这六个比较运算符的操作结果仍然是数字

> [!TIP]
>
> 在 C 中，比较运算符返回的不是 "真" 或 "假" 这两个抽象的概念，而返回的是数字 $1$ 或 $0$；

```c
a == b;  // a 和 b 的值相等，这个表达式的值是 1；否则，该表达式的值是 0
a < b;   // a 小于 b 时，这个表达式的值时 1；其他情况都是 0
```

既然如此；比较结果可以出现在任何整数可以出现的地方。例如，参与算术运算和作为数组的索引

```c
size_t c = (a < b) + (a == b) + (a > b); // c 的值一定是 1（a 和 b 一定会曼满足其中一个条件）

double largeA[N] = { ... };
size_t sign[2] = { 0, 0 };
for (size_t i = 0; i < N; ++i) {
    sign[(largeA[i] < 1.0)] += 1;   // true(1) 或 false(0) 直接当索引
}
// sign[0] = 大于等于 1.0 的数量
// sign[1] = 严格小于 1.0 的数量
```

> 表达式 `sign[(largeA[i] < 1.0)] += 1;` 只使用了一行就做到了 `if` 语句先判断后累加才能作为的结果

**代码示例**

```c
/* compare.c — 比较结果作为数字使用 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    // 比较结果即 0 或 1
    printf("5 < 3  = %d\n", 5 < 3);     // 0
    printf("5 > 3  = %d\n", 5 > 3);     // 1
    printf("5 == 5 = %d\n", 5 == 5);    // 1

    // 三个关系之和一定为 1
    size_t a = 7, b = 7;
    printf("(a<b)+(a==b)+(a>b) = %zu\n",
           (a < b) + (a == b) + (a > b));  // 1

    // 用比较结果做数组索引统计
    double arr[] = {0.5, 2.0, 0.3, 1.5, 0.8};
    size_t count[2] = {0, 0};
    for (size_t i = 0; i < 5; ++i) {
        count[(arr[i] >= 1.0)] += 1;
    }
    printf("< 1.0: %zu, >= 1.0: %zu\n",
           count[0], count[1]);  // < 1.0: 3, >= 1.0: 2

    return EXIT_SUCCESS;
}
```

- [x] **练习 2**：数组索引统计 — 数组 `int A[] = {1,1,0,0,1,0,1}`，用"比较结果当索引"的技巧，统计其中 0 和 1 各有多少个（不用 `if`），保存到 `code/ch04/bitcount.c`

  ```c
  // 核心逻辑
  int A[] = {1, 1, 0, 0, 1, 0, 1};
  int count[2] = {0, 0};
  for (size_t i = 0; i < sizeof(A)/sizeof(A[0]); ++i) {
      ++count[A[i] == 1];  // true→count[1], false→count[0]
  }
  ```

- [x] **练习 3**：完整程序 — 输入一个整数，统计它的二进制表示中 1 的个数（用位运算 + 循环），保存到 `code/ch04/popcount.c`

  ```c
  // 核心逻辑
  int count[2] = {0, 0};
  while (number > 0) {
      ++count[number & 0x1];  // 最低位是 0 还是 1
      number >>= 1;            // 右移，处理下一位
  }
  ```
