## 📋 速览

C 的表达式由操作数和运算符组成，运算符按操作对象分为值运算符、对象运算符和类型运算符三类。表达式计算围绕 `size_t` 展开——无符号算术总是良定义的：溢出时回绕（模 `SIZE_MAX+1`），`/` 和 `%` 不可能溢出。

比较运算符返回 0 或 1，结果可直接参与算术或作为数组索引——一行替代分支。`&&` `||` `?:` 具有短路求值特性，只执行被选中的操作数。`++`/`--` 有前缀后缀之分，副作用应受控：一条语句最多修改一个对象。大多数运算符不保证求值顺序，表达式中的函数调用不应有副作用

| 1 | `n & (n-1) == 0` 为什么能判断 2 的幂？(答案：对于 $2^n$ 的位模式只有第 $n$ 位是 $1$ 其他的全是 $0$，$2^n-1$ 的第 $0 \\sim n-1$位全是 $1$)这个位运算技巧的数学原理是什么？为什么 n=0 时这个表达式也是真？(当 n=0 时，`0 & ?` 始终为 0) | ☑ 已解答 |
| 2 | `sign_count.c` 中用比较结果计算三分类索引——这种技巧能推广到 N 分类吗？极限在哪？（答案：可以。对 N-1 个单调阈值累加 `(x >= t)` 即可；三分类用 `(>0)-(<0)+1` 只需两个比较，是 signum 的整数版。超过 4-5 类时 `switch` 更清晰） | ☑ 已解答 |
| 3 | `++i`（前缀）和 `i++`（后缀）除了返回值不同，有性能差异吗？（答案：现代编译器会进行优化，如果不需要 `i++` 的值就优化为 `++i`）笔记说"前缀不需要临时对象"——这在实际代码中有多重要？(这只是为了应对较为古老的编译器才这样写的) | ☑ 已解答 |
