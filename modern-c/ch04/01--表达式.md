## 📋 速览

C 的表达式由操作数和运算符组成，运算符按操作对象分为值运算符、对象运算符和类型运算符三类。表达式计算围绕 `size_t` 展开——无符号算术总是良定义的：溢出时回绕（模 `SIZE_MAX+1`），`/` 和 `%` 不可能溢出。

比较运算符返回 0 或 1，结果可直接参与算术或作为数组索引——一行替代分支。`&&` `||` `?:` 具有短路求值特性，只执行被选中的操作数。`++`/`--` 有前缀后缀之分，副作用应受控：一条语句最多修改一个对象。大多数运算符不保证求值顺序，表达式中的函数调用不应有副作用

## 📖 知识点


### 知识点 1：表达式


**是什么**

表达式（expression）是一段 *计算值* 的代码；它根据其他值算出另一个值。表达式由 *操作数* 和 *运算符* 组成（运算符可以没有）

**详细解释**

我们将围绕 `size_t` 类型展开学习 C 中的表达式。`size_t` 的值域范围是 `[0, SIZE_MAX]`，`SIZE_MAX` 的大小取决于具体平台

| 平台        | `SIZE_MAX` 的值               |
| ----------- | ----------------------------- |
| $16$ 位平台 | $2^{16}-1=65535$              |
| $32$ 位平台 | $2^{32}-1$ 大约是 $43$ 亿     |
| $64$ 位平台 | $2^{64}-1$ 大约是 $1844$ 亿亿 |

> [!TIP]
>
> 不需要记忆，也不需要自行计算 `SIZE_MAX` 的值。C 标准头文件 `<stdint.h>` 中提供了 `SIZE_MAX` 宏
>
> `size_t` 类型属于 C 的无符号整数类型；意味着 **`size_t` 类型的值永远不会小于 $0$**。这个原则很重要

> **`size_t` 类型表示 `[0, SIZE_MAX]` 范围内的值。**

**操作数与运算符**：C 把计算拆分成两个角色：操作数（operand）是被操作的东西，运算符（operator）是执行操作的符号。例如 `a + b` 中，`a` 和 `b` 是操作数，`+` 是运算符。C 的运算符按操作实体可以分为 $3$ 类

| 类型       | 操作对象                 | 举例                              |
| ---------- | ------------------------ | --------------------------------- |
| 值运算符   | 操作值，算出新值         | `+` `-` `*` `/` `%` `==` `!` `&&` |
| 对象运算符 | 操作对象本身，可能改变它 | `=` `+=` `++` `--` `&`            |
| 类型运算符 | 操作类型，返回大小/对齐  | `sizeof ` `alignof`               |

> 这些运算符在后面的 附录 中列出来了。我们不需要记忆它们；在学习过程中自然会记住的

**代码示例**

```c
/* 查看 size_t 的范围和 sizeof */
#include <stdint.h>
#include <stdio.h>

int main(void) {
    printf("size_t 字节数: %zu\n", sizeof(size_t));
    printf("SIZE_MAX = %zu\n", SIZE_MAX);
    // 64位平台输出: size_t 字节数: 8
    //              SIZE_MAX = 18446744073709551615
}
```
