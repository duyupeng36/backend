## 📋 速览

C 程序由**六种基本词法元素**（特殊词、标点、注释、字面量、标识符、运算符）按语法规则组合而成。理解 C 程序需要区分三个语义层面：

1. **声明** — 告诉编译器标识符代表什么（类型+名字）。所有标识符必须先声明后使用。声明有作用域（文件作用域、块作用域）。
2. **定义** — 声明 + 初始化器（或函数体）= 定义，创建实体并分配存储。每个对象/函数必须恰好有一个定义。
3. **语句** — 执行单元。三种基本类型：迭代（`for`）、函数调用（传值调用）、返回（`return`）。

关键区分：**声明**只描述，**定义**创建实体，**语句**执行动作。

| 1 | 声明和定义的本质区别是什么？（答案：定义是扩展了的声明。定义本质上也是声明，只是需要为创建程序实体）"声明+初始化=定义"这条规则有例外吗？（比如函数：声明加分号是声明，加 `{}` 函数体才是定义）（答案：声明  + 初始化 = 定义说的数据对象，而不是函数） | ☑ 已解答 |
| 2 | 同一个标点 `{}` 在 C 中有三种不同用法（函数体、初始化列表、循环体），`[]` 也有三种（数组声明、下标、指定初始化）。这是 C 的设计特点还是历史负担？（答案：可以根据上下文推断符号的用途，不必为不同的用途设计不同的符号。而且，C 的声明是在模仿使用，去掉声明中的类型就是标识符的使用方式） | ☑ 已解答 |
| 3 | `main` 函数的参数 `argc` 和 `argv` 从哪里来？操作系统是如何把命令行参数传递给 C 程序的？（答案：调用该程序的进程传递过来的；通常操作系统，会计算参数的个数，并将参数打包在一个 `char*` 数组(最后一个元素必须是 `nullptr` 标记数组结束)中传递给程序） | ☑ 已解答 |
