## 📋 速览

C 程序的抽象状态机由值、类型和二进制表示三层构成。基本类型由关键字提供（有 Rank 和四种数据模型），语义类型（size_t、uint32_t 等）由标准库 typedef 提供，是编写可移植代码的起点。窄类型（Rank < 3）参与运算前自动提升为 int，字面量按进制和后缀推导类型（四条规则），浮点字面量默认 double 且存在精度陷阱——十六进制浮点解决精确表示问题。隐式转换遵循 Rank 和符号性规则：同符号按等级升高，混合符号有平台依赖性。初始化器从标量直接赋值到数组指定初始化，C23 引入通用 {}。

## 📖 知识点


### 知识点 3：语义类型


**是什么**

语义类型是标准库通过 `typedef` 定义的类型，它们的名字暗示了该类型的用途

**详细解释**

恰好必须使用 $32$ 位无符号整数时，就应该使用 `uint32_t`（来自头文件 `<stdint.h>`）的语义类型，而不是使用 `unsigned int`。使用语义类型（例如，`size_t` `uint32_t`）是编写可移植程序的起点。下表列出了常用的几种语义类型

| 类型        | 头文件       | 含义                    | 典型用途                  |
| ----------- | ------------ | ----------------------- | ------------------------- |
| `size_t`    | `<stddef.h>` | 大小、基数              | `sizeof` 返回值、数组下标 |
| `ptrdiff_t` | `<stddef.h>` | 指针差值                | 两个指针相减              |
| `uintmax_t` | `<stdint.h>` | 最大宽度无符号整数      | 预处理器算术              |
| `uint{N}_t` | `<stdint.h>` | 宽度为 `N` 的无符号整数 | 预处理器算术              |
| `intmax_t`  | `<stdint.h>` | 最大宽度有符号整数      | 预处理器算术              |
| `int{N}_t`  | `<stdint.h>` | 宽度为 `N` 的有符号整数 | 预处理器算术              |
| `time_t`    | `<time.h>`   | 日历时间（秒）          | `time(0)` 返回值          |
| `clock_t`   | `<time.h>`   | 处理器时间              | `clock()` 返回值          |

> 类型 `time_t` 和 `clock_t` 用于时间处理。它们的具体精度因平台而异，所以它们是"语义类型"——你只关心"这是时间"，不关心它在底层是 $32$ 位还是 $64$ 位。

**代码示例**

```c
/* semantic_types.c — 语义类型示例 */
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

int main(void) {
    int arr[] = {1, 2, 3, 4, 5};

    size_t len = sizeof(arr) / sizeof(arr[0]);
    for (size_t i = 0; i < len; ++i)
        printf("%d ", arr[i]);
    printf("\n");

    ptrdiff_t diff = &arr[4] - &arr[0];
    printf("&arr[4] - &arr[0] = %td\n", diff);

    uint32_t ip = 0xC0A80001;
    printf("IP: %u.%u.%u.%u\n",
           ip >> 24, (ip >> 16) & 0xFF,
           (ip >> 8) & 0xFF, ip & 0xFF);
}
```

- [x] **练习 2**：`size_t` vs `unsigned int` — 为什么用 `size_t` 做数组索引比用 `unsigned int` 更可移植？（提示：参考笔记中四种数据模型表，看 `int` 的宽度变化）
    答案：`size_t` 表示大小、数量的含义；做数组下标语义明确。并且，`size_t` 是平台能够表示的最大整数值。`unsigned int` 在不同平台上的最大值可能不同；例如，在 LP32 上，`unsigned int` 的最大值是 $2^{16} - 1 = 65535$，如果数组长度超过了这个值，后面的数组元素将无法访问
