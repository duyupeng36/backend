## 📋 速览

C 程序的抽象状态机由值、类型和二进制表示三层构成。基本类型由关键字提供（有 Rank 和四种数据模型），语义类型（size_t、uint32_t 等）由标准库 typedef 提供，是编写可移植代码的起点。窄类型（Rank < 3）参与运算前自动提升为 int，字面量按进制和后缀推导类型（四条规则），浮点字面量默认 double 且存在精度陷阱——十六进制浮点解决精确表示问题。隐式转换遵循 Rank 和符号性规则：同符号按等级升高，混合符号有平台依赖性。初始化器从标量直接赋值到数组指定初始化，C23 引入通用 {}。

## 📖 知识点


### 知识点 9：初始化器


**是什么**

初始化器在对象定义是为其提供初始值。对于聚合对象使用 `{...}` 形式的初始化器，对于标量对象可以直接使用表达式。从 C23 开始，花括号形式的初始化器适用于所有类型的对象

**详细解释**

一个未初始化的变量，值是不确定的，这往往是 bug 出现根源。因此，《Modern C》从开始就强调

> [!TIP]
>
> 所有变量都应该被初始化。 唯一的例外是需要极致优化的热点代码，而现代编译器会把多余的初始化优化掉，所以大胆写就行。

C 语言中的基本类型都是 **标量** 类型，直接使用一个表达式初始化——表达式值自动转成目标类型。注意，不要出现窄化类型转换情形

```c
double a = 7.8;
double b = 2 * a;
double c = { 7.8 };     // {} 可加可不加
double d = { 0 };
```

数组是我们已经见过的聚合类型，虽然还没有正式学习。现在，我们提前学习数组的初始化器。直接看例子

```c
double A[] = { 7.8, };          	 // 一个元素，类型由初始化器确定长度
double B[3] = { 2 * A[0], 7, 33, };  // 三个元素，末尾逗号合法
double C[] = { [0] = 6, [3] = 1, };  // 指定初始化器：C[0]=6, C[1]=0, C[2]=0, C[3]=1
```

1. `double A[]` 声明时没有提供数组的长度，对于数组而言，这是不完整的。这种情况下，必须提供初始化器，以便于编译器可以从初始化器中推导数组的长度
2. `double B[3] = { 2 * A[0], 7, 33, };` 形式的初始化称为顺序初始化。初始化器末尾的逗号（`,`）是合法的，不必删除。保留它可以方便后续增加初始器中的元素
3. `double C[] = { [0] = 6, [3] = 1, };` 形式的初始化器称为指定初始化器。它明确定义了那个位置放置什么值，未指定的自动填充 $0$

> [!TIP]
>
> 对所有聚合类型，优先用指定初始化器。它比按位置填更健壮——增删元素不会导致数据错位

4. C23 引入了**通用默认初始化器** `{}`：

```c
double D[100] = { };   // C23：全部初始化为 0
int    x     = { };    // C23 标量也可以
```

> C23 之前只能写 `{0}`。`{}` 统一了所有类型的默认初始化——所有位清零。

**代码示例**

```c
/* initializers.c — 三种初始化方式和 C23 默认初始化器 */
#include <stdio.h>

int main(void) {
    // 标量初始化：表达式自动转换
    double a = 7.8;
    double b = 2 * a;

    // 顺序初始化
    double B[3] = { 2 * a, 7.0, 33.0, };
    for (size_t i = 0; i < 3; ++i)
        printf("B[%zu] = %.1f\n", i, B[i]);

    // 指定初始化器：未指定的自动填 0
    double C[] = { [0] = 6.0, [3] = 1.0, };
    printf("C 的长度: %zu\n", sizeof(C) / sizeof(C[0]));
    for (size_t i = 0; i < 4; ++i)
        printf("C[%zu] = %.1f\n", i, C[i]);

    // C23 通用默认初始化器
    int x = { };
    double D[5] = { };
    printf("x = %d\n", x);               // 0
    printf("D[2] = %.1f\n", D[2]);        // 0.0
}
```
