## 📋 速览

C 程序的抽象状态机由值、类型和二进制表示三层构成。基本类型由关键字提供（有 Rank 和四种数据模型），语义类型（size_t、uint32_t 等）由标准库 typedef 提供，是编写可移植代码的起点。窄类型（Rank < 3）参与运算前自动提升为 int，字面量按进制和后缀推导类型（四条规则），浮点字面量默认 double 且存在精度陷阱——十六进制浮点解决精确表示问题。隐式转换遵循 Rank 和符号性规则：同符号按等级升高，混合符号有平台依赖性。初始化器从标量直接赋值到数组指定初始化，C23 引入通用 {}。

## 📖 知识点


### 知识点 7：字符和字符串字面量


**是什么**

字符字面量是放在 `'...'` 引号之间的**单个字符**，它的值由 C 标准隐式确定。字符串字面量是放在 `"..."` 引号之间的**字符序列**

**详细解释**

字符字面量将字符包围在单引号（`'...'`）之间，其类型是 `int`，而不是 `char`。`sizeof('a')` 的值应该是 $4$ 而非 $1$

字符 `\` 在字符字面量中存在特殊含义：用于表示无法直接输入的字符。由反斜杠 `\` 开头的字符字面量称为 **转义字符**。下表列出了几个常用的转义字符

| 转义 | 含义     | 转义 | 含义           |
| ---- | -------- | ---- | -------------- |
| `\n` | 换行     | `\f` | 换页           |
| `\r` | 回车     | `\\` | 反斜杠         |
| `\t` | 水平制表 | `\'` | 单引号         |
| `\v` | 垂直制表 | `\"` | 双引号         |
| `\a` | 响铃     | `\?` | 问好           |
| `\b` | 退格     | `\0` | 空字符（值 0） |

```c
'a'      // 字符 a 的整数值
'\n'     // 换行符
'\\'     // 反斜杠本身
'\0'     // 空字符，值为 0
'0'		 // 字符 0
```

字符串字面量将字符包围在双引号（`"..."`）之间，其类型是 `char[]`；也就是说，C 语言中的字符串本质上字符数组；为了确定字符串的结束位置，C 标准规定 `\0`（空字符）用于标记字符串的终止，因此，空字符 `\0` 也称为终止符

编译器如果如果发现了多个相邻的字符串字面量时会自动将它们拼接成一个字符串

```c
puts("first line\n"
     "second line\n"
     "third line");
// 等价于 puts("first line\nsecond line\nthird line");
```

> 这对写长字符串很有用——不需要一行写到底，可以分段写

> [!WARNING]
>
> 请特别注意：`'a'` 和 `"a"` 是完全不同的
>
> + `'a'` 是 `int` 类型的值，具体是多少取决于编译环境使用的字符集（例如，ASCII 字符集的值是 $97$）
> + `"a"` 是 `char[2]` 类型的值，包含了字符 `'a'` 和 字符 `'\0'`

**代码示例**

```c
/* char_string_literals.c — 字符和字符串字面量 */
#include <stdio.h>

int main(void) {
    // 字符字面量是 int，不是 char
    printf("sizeof('a')  = %zu (int!)\n", sizeof('a'));
    printf("sizeof(char) = %zu\n", sizeof(char));

    // 'a' 和 "a" 完全不同
    printf("'a'  = %d (int)\n", 'a');
    printf("\"a\"  = %zu 字节 (char[2]: 'a' + '\\0')\n", sizeof("a"));

    // '0' 和 '\\0' 截然不同
    printf("'0'  = %d\n", '0');    // ASCII 48
    printf("'\\0' = %d\n", '\0');  // 0

    // 字符串自动拼接
    printf("这三行会被"
           "编译器自动"
           "合并为一行\n");
}
```
