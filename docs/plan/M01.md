# M1 学习计划（2026-11-11 → 2026-12-08）· C 语言与底层工具链

> 对应总计划「M1 · C 语言与底层工具链（快节奏打底）」。时间预算：每周 ≈ 20h（工作日 2h × 5 + 周末 5h × 2），全月 ≈ 80h。
> LeetCode M5 才启动，本月不安排刷题；「英语线」每周精读 1 篇英文技术文章（计在 20h 内）。

## 本月目标

1. C 语法速通：指针、数组、字符串、结构体、函数指针、手动内存管理——达到「读 C 代码无障碍、写中小程序不出内存错」。
2. 工具链上手：GCC 编译链接全流程、GDB 调试、Makefile/CMake、静态/动态库。
3. Linux 基础：shell、文件权限、进程查看、`/proc`。
4. **两个交付物**：`c-utils` 库（动态数组 + 字符串库 + 单元测试）+ GDB 实战调试记录文章。

## 环境准备（W1 第 1 天，约 1h）

本机现状（已实测）：Ubuntu 26.04 (WSL)、gcc 15.2、make 4.4、git 2.53 已就绪。

```bash
# 需要安装：
sudo apt update && sudo apt install -y gdb cmake valgrind
# 验证
gcc --version && gdb --version && cmake --version && valgrind --version
```

- VSCode + WSL Remote + C/C++ 扩展（ms-vscode.cpptools），断点调试直接连 gdb
- 新建仓库 `c-utils`（独立建仓，与 backend 总控仓库同级：`~/github.com/duyupeng36/c-utils`）
