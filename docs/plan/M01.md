# M1 学习计划（2026-11-11 → 2026-12-08）· C++ 基础语法与底层工具链

> 对应总计划「M1 · C++ 基础语法与底层工具链」。**C++ 先行**：C++ 基础语法覆盖绝大部分 C 语法结构，C 语言专题周后移至 M2-W1。
> 时间预算：每周 ≈ 20h（工作日 2h × 5 + 周末 5h × 2），全月 ≈ 80h。
> LeetCode M5 才启动，本月不安排刷题；「英语线」每周精读 1 篇英文技术文章（计在 20h 内）。

## 本月目标

1. C++ 基础语法速通：类型/控制流/函数、指针与数组、字符串、结构体、引用 vs 指针、重载、命名空间、动态内存——达到「写中小程序不出内存错」。
2. 工具链上手：g++ 编译链接全流程、GDB 调试、Makefile/CMake、静态/动态库。
3. Linux 基础：shell、文件权限、进程查看、`/proc`。
4. **三个交付物**：C++ 基础练习集（字符串处理 + `vec` 类 + 测试）、GDB 实战调试记录文章、工具链产物观察笔记。
